# Eksik araştırma ve edinim listesi

## Birinci öncelik
Hedef Warband sürümünün tam Module System paketi. Özellikle header_operations.py, header_common.py, bütün process_*.py dosyaları, ID üretimi ve Native module dosyaları gerekir. Bunlar olmadan kesin operand kodlaması veya dosya formatı garantisi verme.

## İkinci öncelik
[S01] tam metni ve [S03] resmî dokümantasyon aynasının diğer bölümleri. [S02] operasyon açıklamalarını hedef header ile karşılaştır. [S07] indirilebilir rehberin lisansını ve içindekileri kontrol et.

## Genişletilecek başlıklar
ModMerger, WRECK, WSE/WSE2, OpenBRF, Lav operations başvuruları, The Forge rehber indeksleri, multiplayer event protokolleri, savegame uyumluluğu ve string/localization pipeline.

Bunlar bu araştırmada ayrı ayrı doğrulanmış kaynaklar değildir; sonraki arama başlıklarıdır. Doğrulanmış URL veya destek garantisi olarak kullanma.

## Arama sorguları
- Warband process_operations operand encoding
- Warband header_common variable tags
- Warband Module System script condition failure
- Warband simple triggers regular triggers mission triggers
- Warband dialogs tuple schema
- Warband WRECK compiler
- Warband WSE2 operations documentation
- Warband ModMerger documentation

## Bir dosyayı belgelerken
Dosya yolu ve hash; kayıt şeması; zorunlu/opsiyonel alanlar; sayısal dönüşüm; isim çözümü; örnek girdi; resmî derleyici çıktısı; mikro test sonucu; kaynak URL; doğrulama seviyesi kaydedilmeli.

## Telif ve arşivleme
Topluluk yazılarının tamamını izinsiz yeniden dağıtmak yerine bağlantı ve kısa özgün açıklama kullan. Kod depolarını yeniden dağıtmadan önce lisanslarını ayrı ayrı kontrol et. Bu paket kaynak sayfalarını yeniden yayımlamaz.
