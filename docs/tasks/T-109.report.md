Uncertain / deliberate choices
- The spec's Goal snippet is aspirational: `say "…"` without parentheses and `if player.has(…)` are not parseable in today's language (`say` is a fn call, and a fn call is not accepted as an `if` condition). Rather than extend the general condition grammar (outside the task's listed steps), the golden and guide use a compiling block close to the example: `if player.gold >= 10 { player.gold -= 10; say("@…") }`, with `time.hour >= 12` as the `when`. `time.hour.get` was added to the library so the `when` is exactly the Goal's.
- New diagnostics follow the codebase convention (English message + code + source span/help); the Turkish guide/CHECKUP document them in Turkish, as every other error table does. If “Errors in Turkish” meant the diagnostic strings themselves, that would break the existing all-English diagnostics.
- The polygon unit/multiplier (map units × 100) is the one given in the spec's Known facts and supported by the kit (`position_get_x/y` = meters × multiplier, Native's `set_fixed_point_multiplier 100; position_set_x pos0 7050` = 70.5 m).
