# T-130: easy vocabulary for operations, generated from the kit (YÖN-3 L1a)

Status: ready
Budget: $4.00
Steps: 350

## Goal

Every kit operation gets an easy English name generated by rules, not by hand: `agent_get_position(dest, agent)` → `agent.position`, `agent_set_speed_modifier(agent, v)` → `agent.speed_modifier = v`, conditions → bool. Output is data the compiler and the editor will use.

## Known facts

- Rules and numbers: docs/meclis/yon3/dil/D3-SOZLUK.md (read it fully; it was measured with python on the atlas). Decision: docs/meclis/yon3/dil/KARAR-DIL.md §2, §5 (one name per concept; numbered raw access is not "easy").
- Atlas: `target/uw-staging/atlas.json` (in your worktree): `ops` (name, code, signature, lhs, can_fail), `constants` (name, value, module, line). Kit sources (read only): `target/ref/kit/` (= `Module_system 1.171/`), e.g. header_operations.py comments, module_constants.py slots.
- Load the atlas with `uw_atlas::Atlas::from_path`. Put the generator in a new crate `crates/uw_easy` (add to workspace members) with a `uw easy` subcommand ONLY if uw_cli/src/main.rs edits stay to 2-3 lines.

## Steps

1. Implement D3's rules R1–R12 + the namespace rule, plus the two extra rules D3 proposed ("subject in second parameter", "writes reg0").
2. Write `kit-meta/easy/ops.json`: one record per op: `easy`, `native`, `kind` (property_get/property_set/condition/method/function/flow/text), `subject` type, params, `rule`, `doc` (header_operations.py comment + signature), `line`.
3. Ops no rule can name go to `kit-meta/easy/manual.toml` as TODO entries (easy name empty) — do not invent names.
4. One name per concept: detect two ops producing the same easy name; resolve by rule priority and list remaining clashes in the report.

## How to test

crates/uw_easy/tests/ops.rs: on the real atlas (skip with note if absent): ≥ 900 ops named automatically; no duplicate easy names; `agent_get_position` → `agent.position`; `agent_set_speed_modifier` → `agent.speed_modifier`; `key_is_down` is a condition. A small fixture-atlas test too.

## Done when

- ops.json generated and committed; counts (auto / manual / clashes) in the report. Build and tests pass.

## Do not

- Do not edit crates/uw_check, uw_syntax, uw_start. Never invent native names.
