# T-004: uw graph — text tree of what leads where

Status: ready
Budget: $0.80
Steps: 200

## Goal

From one Native thing, show the chain of what it leads to (menus, scripts, dialogs...) as an indented
tree, so the owner sees the flow without reading code.

## Known facts

- `crates/uw_cli` is a binary crate (`src/main.rs`). Add ONLY one `mod graph;` line to `src/main.rs`;
  do not wire a command (the reviewer does). Put `#[allow(dead_code)]` on pub items not yet used so the
  build has no warnings.
- Model API (`crates/uw_cli/src/model.rs`, read it): `Model::new(Atlas)`, `Target` (Entry{table,index} |
  Global | Op | Const), `model.outgoing(&Target) -> &[(Target, Option<String>)]` (what an entry
  mentions + op), `model.label(&Target)`, `model::entry_hint(table, entry)`, `model::short(text, n)`.
- Fixture: `crates/uw_cli/tests/fixtures/atlas_refs.json` (read it), load with
  `uw_atlas::Atlas::from_path(concat!(env!("CARGO_MANIFEST_DIR"), "/tests/fixtures/atlas_refs.json"))`.

## Steps

1. New file `crates/uw_cli/src/graph.rs`: `pub struct TreeLine { pub depth: usize, pub target: Target,
   pub label: String, pub hint: Option<String>, pub op: Option<String>, pub repeat: bool }`.
2. `pub fn tree(model: &Model, root: &Target, max_depth: usize) -> Vec<TreeLine>`: depth-first from root
   following `model.outgoing`, only `Target::Entry` children, each child once per parent (keep the first
   op), in outgoing order. A target already shown earlier gets `repeat: true` and is not expanded.
   Root: depth 0, op None.
3. `pub fn render_text(lines: &[TreeLine]) -> String`: per line two spaces per depth, label, then
   `  (op)` if any, `  "hint"` via `short(hint, 50)` if any, `  ↺` if repeat; newline after each.

## How to test

Unit tests in graph.rs: tree from script `game_start` of the fixture has its children at depth 1 with
ops; max_depth 0 gives only the root; an inline Atlas JSON string where two scripts call each other
("script_a" / "script_b" inside call_script statements) terminates and marks the repeat; render_text
checked with an exact string on a small case.

## Done when

- Tests pass; `cargo build --workspace` has no warnings.

## Stop and report if
