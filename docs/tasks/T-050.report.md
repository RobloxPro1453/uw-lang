- New `Report::shape_breakdown(&self) -> Vec<(String, usize)>`: walks every accepted text line by line and puts each Native-shaped line into exactly one class, returned in the spec's order with zero-count classes left out. Rules, first match wins:
  1. `compute-then-test arm` — a raw `try_begin()` whose next body line is not an `if … {` head (mirrors `if_arms`/`cond_parts`, where every arm but a trailing `else` must start with condition ops);
  2. `guard condition mid-block (neg|)` — a line containing `neg|`;
  3. `this_or_next| chain outside an if head` — a line containing `this_or_next|` (checked first, so a line with both flags counts once, as a chain member);

  5. `other` — everything else (e.g. a shell's `try_end()`, or a shell the rules above do not explain).
