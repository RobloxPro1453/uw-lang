# T-027: Extract operation blocks: mission templates (module_mission_templates)

Status: ready
Budget: $1.00
Steps: 250

## Goal

`uw_decomp::extract::mission_templates::blocks(atlas)` returns every operation block of mission templates (module_mission_templates) as `Block`s, so the
round-trip runner can decompile and measure them (kaldıraç plan, docs/meclis/DEVIR.md 00000).

## Known facts

- Skeleton: crates/uw_decomp/src/lib.rs (`Block {table, index, path, label, ops}`, `items` unwraps
  `{"list": [...]}`, `parse_ops` reads a block or returns None). Fill ONLY
  crates/uw_decomp/src/extract/mission_templates.rs.
- Entries: `atlas.tables["<table>"].entries`, each `Entry {index, name, value}`; `value` is the kit
  tuple as JSON. `path` counts list/tuple positions; `{"list": …}` wrappers are not counted.
- Kit layout comments (read-only): `Module_system 1.171/module_<table>.py` file header.
- mission_templates: value = [id, flags, type, description, spawn records, triggers]; each trigger = [check interval, delay, rearm, condition ops, consequence ops] -> paths [5,i,3], [5,i,4]. Verify the field index of the trigger list in the kit header before coding.
- The real atlas (not in git) is at target/uw-staging/atlas.json (6.5 MB) when the project was built.

## Steps

1. Implement `blocks` for the fields above; label like `<table>/<name or index>/<part>`.
   A field that should be a block but `parse_ops` returns None: emit nothing for it, but count
   it (`pub fn unreadable(atlas) -> usize` in the same file).
2. Unit test with a tiny inline atlas (`uw_atlas::Atlas::from_str`, shape like
   crates/uw_cli/tests/fixtures/atlas_golden.json) holding 2 entries of this table.
3. A test that reads ../../target/uw-staging/atlas.json if it exists (returns early otherwise), prints
   the block count and `unreadable`, and asserts count > 0 and unreadable == 0.

## How to test

The inline-atlas test asserts exact paths, labels and op counts of each block; it fails if a field
index is wrong. The real-atlas test is the coverage proof; put its printed numbers in your report.

## Done when

- Both tests pass; `cargo test --workspace` green; report states the real block count.

## Do not

- Touch any file except crates/uw_decomp/src/extract/mission_templates.rs. No kit writes.

## Stop and report if
