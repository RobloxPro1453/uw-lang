# T-129: uw_start: faction, relation, quest, item and world operations

Status: ready
Budget: $3.00
Steps: 300

## Goal

The dry run models the remaining operations of Native's game_start: faction relations, quests, item probabilities, time and positions.

## Known facts

- Crate `crates/uw_start` runs Native's `script_game_start` without the game (read src/lib.rs top
  comment and src/families/mod.rs rules). Families read operands with `m.get`, store with `m.set`,
  read record cells with `m.read(Cell::field(table, index, "field"))` / `Cell::slot`, write with
  `m.write`, build results with `Val::derived(n, &[inputs])`, and record start values come from
  `m.initial_field_text(table, index, field)` (the field text `uw new` prints; field names are in
  `kit-meta/records/<table>.toml`).
- The kit and sample mods are git-ignored; read-only copies are inside your worktree:
  `target/ref/kit/` (= `Module_system 1.171/`). Operation meanings: `target/ref/kit/header_operations.py`
  (each op has a comment). The built atlas is `target/uw-staging/atlas.json`.
- Unit-test style to copy: `crates/uw_start/tests/flow.rs` (tiny hand-made atlas, ops by name).
- The real run (`cargo test --release -p uw_start -- --ignored --nocapture`) prints the unmodelled
  operations; do NOT run it in debug (too slow).
- Never guess an operation's effect: if the engine computes something the records do not hold
  (positions after AI movement, wages …), leave it unknown.
## Steps

Implement in `crates/uw_start/src/families/faction.rs` (factions, relations, quests, items, time, positions; you may add more files under families/ and register them in families/mod.rs `exec` chain AFTER the existing ones). Unmodelled counts: store_relation 27,300; set_relation; store_current_hours 7,292 (game start = hour 0: certain); set_item_probability_in_merchandise 3,740; reset_item_probabilities 110; check_quest_active 150; quest_* ; faction_set_slot with unknown target 155 (investigate why the target is unknown: report the script/op); game_get_reduce_campaign_ai 95 (a game option: unknown); position_get_y / position_get_z / map_get_*_position_around_position (positions: unknown unless from a static record); set_relation; faction_set_color/name; store_num_parties_of_template is party-family (skip).
- Relations: start values from kit-meta/records/factions.toml relations list; write `Cell::field("factions", f, "relation <g>")`; set_relation is symmetric in the engine only if the op comment says so — check.

## How to test

- Unit tests in crates/uw_start/tests/faction_t129.rs on a tiny atlas: relation read from the record, set_relation then store_relation sees it, store_current_hours = 0, quest active false at start. Each asserts the op is absent from `m.report.unknown_ops`.
