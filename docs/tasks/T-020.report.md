What changed (only crates/uw_decomp/src/decompile.rs):
- `decompile` builds a small `Printer` (atlas + the `neg` / `this_or_next` code bits read via `atlas.op(...)`) and joins lines with `\n`.
- Raw mode (`raw_into`, `raw_line`): one `name(args)` per op. Flag bits are stripped with `code & !(neg|this_or_next)` BEFORE `op_for_code`, so a flagged code that the atlas also lists as its own alias (e.g. `neq` = `neg|eq`) prints as `neg|eq`, not `neg|neq`. Prefix order is `neg|this_or_next|name` as the spec writes it. Operands follow the spec: int (negative ok), `$`/`:` verbatim, identifier + `atlas.resolve_ref` hit as a bare name, everything else as text escaping `\`, `"`, newline. Unknown codes print `// unknown operation <code>`.
- Indentation (both modes) comes from `Kind::Open` (`try_begin`, any `try_for_*`), `Kind::End` (`try_end`/`end_try`), `Kind::Else` (`else_try`/`else_try_begin`, dedented to the opener's level). 4 spaces per level.
- Structured mode (`structured_into`, `if_arms`, `cond_parts`, `cond_text`, `if_into`): `assign($x/:x, v)` prints as `x = v`; a `try_begin` whose matching `try_end` is found via block counting is printed as `if / else if / else` only when every arm starts with one or more condition ops (`can_fail`, eq/gt/ge, or flagged) and only a trailing arm may have none; each body is printed recursively; otherwise the whole try block stays raw. Conditions: eq/gt/ge -> `== > >=`, `neg|` of those -> `!= < <=`, other `neg|op` -> `not op(...)`, a `this_or_next…` run ending in a plain op -> `a or b or c`, parts joined by `and`.
- Tests (tiny inline atlas via `Atlas::from_str`, incl. a `parties` table with ref_tag `p`/`town_6`): `decompile_raw_prints_flags_and_indents_blocks` (all three flag forms, negative int, indentation), `decompile_raw_quotes_text_and_resolves_names` (no-operand op, bare ref vs unknown string, text with an embedded quote/backslash/newline, unknown code), `decompile_structured_writes_assignments_as_equality`, `decompile_structured_if_else_if_else`, `decompile_structured_or_chain_joins_by_or`, `decompile_structured_joins_conditions_by_and_not_by_not`, `decompile_structured_keeps_unclean_and_nested_tries` (non-clean try kept raw, nested if inside an arm, raw `try_for_range` body still indented).
