# T-164: mod mining - strings-text

Status: ready
Budget: $2.00
Steps: 300

## Goal

Mine 17 real open-source Warband mods for one topic, so the UW language and compiler can be designed
from how modders REALLY use the Module System (owner: "these mods are a gold mine").
Topic: Text handling: module_strings.py and quick strings (@...), string registers (s0..), str_store_* building, number formatting, localisation, displaying messages, colours, how long texts are composed.

## Known facts

- All 17 mods are copied read-only into your worktree: `target/ref/mods/<NN-name>/` (Python Module
  System files; some have sub-folders such as `ModuleSystem/`). The plain kit (Module System 1.171)
  is `target/ref/kit/`; use it to tell what the mods added or changed.
- Cite evidence as `mods/<NN-name>/<path>:<line>`. Use `grep`/search, do not read whole files.

## Steps

1. Search all 17 mods for the topic. Look at at least 8 different mods.
2. Write `docs/bilgi/maden/strings-text.md` (at most 200 lines):
   - "Patterns": a table `| # | pattern (generic, one line) | how it is done in MS (2-3 lines, operations named) | mods using it (count of 17 + names) | evidence (file:line, 1-3) |`, 10-25 rows, most common first;
   - "Engine facts learned": concrete engine behaviours/limits the mods reveal, each with evidence;
   - "Pain points": what the modders had to write repeatedly or fight against;
   - "For UW": 5-10 lines, what a high-level language/compiler should do for this topic
     (generate automatically, hide, offer as a general verb) - generic wording, no mod names.

## How to test

Doc-only task: no code changes. `cargo build --workspace` must still pass. Every evidence entry
must be a `file:line` that really exists under `target/ref/mods/`.

## Done when

- `docs/bilgi/maden/strings-text.md` exists with the four sections and at least 8 mods cited.

## Do not

- Do not edit code, `target/ref/` or anything outside `docs/bilgi/maden/strings-text.md`.
- Do not copy mod code longer than 3 lines into the doc (licenses are mixed): describe it.
- Do not invent: no evidence line, no row.

## Stop and report if

- `target/ref/mods/` is missing or has fewer than 10 mod folders.
- A test still fails after 5 steps on it.
