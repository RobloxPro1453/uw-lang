# T-094: `uw rename praven "Adam Siken"` — the name and every text that mentions it, translations flexible

Status: ready
Budget: $1.80
Steps: 450

## Goal

The owner renamed Praven by hand: the map showed the new name, but "join a caravan to Praven…" (menu
options) and "Merchant of Praven" (a troop) kept the old one, and Turkish lost its " Şehri" suffix
(docs/bilgi/proje-kipi-deneyi.md, ROADMAP "Ad değişince öbür metinler"). In a project folder:

```
uw rename praven "Adam Siken"            # lists, asks y/n per group, then writes
uw rename praven "Adam Siken" --list     # only lists
```

## Known facts

- Project folder: record files (`name "Praven"` in parties/towns/town_6.uw), `languages/<lang>/*.csv`
  lines `id|text` (T-089 copies them in), names.uw. Builds drop translations of renamed records
  (crates/uw_cli/src/build_project.rs `install_languages`, `filter_translation_lines`).
- Owner's decision (ROADMAP): flexible. Default keeps the translation's pattern: old name replaced inside
  the old translation ("Praven Şehri" -> "Adam Siken Şehri"); a record may set its own per-language name;
  a project setting can drop/add a suffix for all towns.

## Steps

1. New crates/uw_cli/src/rename.rs + `rename` in main.rs USAGE/dispatch (works from the project folder or
   `uw rename <dir> …`, like `uw build`).
2. Find: the record's own name field; every other record text (any quoted string in project .uw files)
   containing the old name as a whole word; every languages line containing it. Print grouped:
   own name / other English texts / translations, with file:line.
3. Apply (after a y/N per group; `--yes` applies all): replace whole-word occurrences; for the record's own
   translation lines replace the old name inside the line (pattern kept). Never touch Native or the game
   folder; write files atomically (temp + rename).
4. build-project: a translation line that already holds the record's new name is kept (not dropped).
5. uw.toml `[languages.<lang>] town_suffix = ""` (or any text): on build, the installed translation of every
   town/castle/village name has the Native suffix replaced by this one; documented in the report.

## How to test

Temp project tests: --list finds own name, a menu text and a tr line; apply with --yes rewrites them and
nothing else (other bytes identical); build filtering keeps a renamed-and-translated line.

## Done when

- Build and tests pass; `uw new --check` exact.
