# T-098: VS Code extension v0: colours for .uw files

Status: ready
Budget: $0.80
Steps: 200

## Goal

Opening a .uw file in VS Code shows keywords, strings, comments, numbers, `$globals`, `:locals`, dotted
object words and operation calls in colour, with bracket matching and `//` comment toggling.

## Known facts

- Keywords and forms: crates/uw_syntax/src/lib.rs (top-level `mod override in new troop on fn save every`,
  statements `if else for require attempt option when after text change remove`), examples in
  crates/uw_cli/tests/golden/*/input.uw and lib/core.uw.

## Steps

1. editors/vscode/: package.json (name `uw-lang`, no publisher secrets), language-configuration.json,
   syntaxes/uw.tmLanguage.json, README.md (Turkish: how to install from the folder with
   `code --install-extension` after `npx @vscode/vsce package`, or by copying to ~/.vscode/extensions).
2. A small node-free test: a Rust test or a script under editors/vscode/test/ that checks the grammar JSON
   parses and every keyword from the list above appears in it.

## How to test

The check fails if a keyword is missing or the JSON is invalid.

## Done when

- Build and tests pass.

## Do not

- Touch anything outside editors/vscode/ (and one test file if Rust).

## Stop and report if

- Packaging needs a network download you cannot do; write the steps in README instead.
