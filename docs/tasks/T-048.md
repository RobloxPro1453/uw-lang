# T-048: Decompiler prints register, position and slot names (P2 readability)

Status: ready
Budget: $1.50
Steps: 350

## Goal

Decompiled UW shows `reg0`, `pos1`, `slot_troop_…` instead of `72057594037927936`, `1`, `2` where the kit
has exactly one such name, and `uw roundtrip` stays 9113/9113. Decision: docs/arsiv/meclis-yon1-yon2/YON2-KARAR.md §4.5.

## Known facts

- Example today: `assign(72057594037927936, $g_multiplayer_team_1_faction)` (target/uw-native/scripts.uw);
  kit: `reg0 = opmask_register| 0` (Module_system 1.171/header_common.py:563), `pos1 = 1` (:498).
- Atlas: `atlas.constants` (kit constants with values) and `atlas.ops` (op table; check which argument
  information it has). The kit has 572 `slot_*` constants in module_constants.py; many share a value.
- Decompiler: crates/uw_decomp/src/decompile.rs. Round-trip runner: `uw roundtrip`.

## Steps

1. Registers: an argument carrying the register tag prints as the kit name (`reg0`…); it must compile back
   to the same number (check that uw_check resolves kit constants; if not, report).
2. Positions: only for arguments the op table marks as a position → `posN`.
3. Slots: only for slot arguments of `troop_`/`party_`/`item_`/`faction_`/`scene_`/`agent_`/`quest_`/
   `team_`/`scene_prop_`… ops: candidates = kit constants `slot_<object>_*` with that value; print the name
   only when there is exactly one candidate, else the number. Object kind comes from the op name prefix;
   never guess a name.
4. Tests: unit tests on single ops; real atlas round trip stays 9113/9113 (report how many arguments got
   names, per kind).

## How to test

A unit test asserts the `assign(reg0, …)` text and that it compiles back to the same op; the round-trip
count fails if any name does not read back to its number.

## Done when

- `uw roundtrip` 9113/9113; counts reported. Workspace tests green.

## Do not

- Touch records.rs, project/, crates/uw_decomp/src/roundtrip.rs, crates/uw_cli/src/roundtrip.rs.

## Stop and report if

- The op table cannot tell position/slot arguments apart. A test still fails after 5 steps.
