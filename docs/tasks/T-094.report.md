What changed
- New `crates/uw_cli/src/rename.rs`: `uw rename <record> "<new name>" [--list] [--yes] [--atlas <file>]`, or `uw rename <dir> <record> "<new name>" …`. It resolves the record through the project's `names.uw` (`praven` -> `p_town_6`, a kit reference works too), reads the record's own `name` field from its file (`layout::path_for`), and scans:
  - every quoted string in the project's `.uw` files (`//` comments skipped, escapes honoured) for the old name as a whole word, split into "own name" and "other English texts";
  - every `languages/**/*.csv` `id|text` line, in "translations".
  Each hit is printed as `relative/file:line  <source line>`. `--list` writes nothing; otherwise it asks `[y/N]` per non-empty group (`--yes` accepts all) and only the confirmed hits are replaced. Only the text inside each quoted string / after the `|` changes, so comments, record headers, `names.uw` and other bytes stay identical. Files are rewritten with temp file + rename, and a path outside the project folder is refused. If the project's own name is already the new name (the owner's hand-renamed town), the Native display name is used as the old name so the other texts are still found.
- `crates/uw_cli/src/main.rs`: `mod rename`, two USAGE entries, and the `rename` dispatch (works from the project folder or with a folder, like `uw build`).
- `crates/uw_cli/src/build_project.rs`:
  - Step 4: `renamed_keys` now returns key -> new text, and `filter_translation_lines` keeps a line of a renamed record when its text already contains the new name as a whole word (otherwise it is dropped with the old warning). The filtering helpers take one `LanguageRules` struct (renamed keys, towns, suffixes) instead of the old set.
  - Step 5: `town_names` collects town/castle/village ids from the record's own folder (`parties/towns|castles|villages/…`) with the project name and the Native name; `with_town_suffix` rewrites each kept `id|text` line of that language whose text starts with one of those names to `<project name><configured suffix>`. A text that starts with neither name (a fully localized one) is left alone.
