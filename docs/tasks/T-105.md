# T-105: `uw find "<text>"` — where a name appears in other texts (owner's Praven test)

Status: ready
Budget: $0.80
Steps: 250

## Goal

The owner renamed Praven to "Adam Siken", but the old name stayed inside other texts (start menu
"join a caravan to Praven, in the Kingdom of Swadia", troop "Merchant of Praven"). `uw find praven` in a
project lists every text that contains it, so nothing is missed:

```
cities/town_1.uw:2      party town_1        name   "Praven"
menus/start_phase_2.uw:14  menu start_phase_2  text   "...join a caravan to Praven, in the..."
troops/...uw:3          troop merchant_town_1 name "Merchant of Praven"
languages/tr/parties.csv:7  ...               "Praven Şehri"      (only if the project has languages/)
3 + 1 yer bulundu.
```

## Known facts

- Project layout and loading: crates/uw_decomp/src/project/ (layout.rs, load.rs, mod.rs); `uw rename`
  (crates/uw_cli/src/rename.rs, T-094) already walks project texts and language files — reuse its walker
  instead of writing a new one.
- Matching: case-insensitive, whole word by default (`Praven` matches, `Pravenia` does not); `--part` for
  substring. Show record kind + id + field, file:line, and the text shortened around the match.

## Steps

1. crates/uw_cli/src/find.rs + one dispatch line and USAGE line in main.rs.
2. `--json` prints one object per hit (`file,line,record,field,text`) for the editor later.
3. Tests crates/uw_cli/tests/find.rs on a temp project: whole word vs `--part`, CSV hit, Turkish summary.
