# T-122: `kit-meta/hardwired.toml` — records the engine requires (for `base = empty`)

Status: ready
Budget: $1.50
Steps: 200

## Goal

A data file that lists, per table, the records and positions the game engine itself depends on, so a
from-scratch mod (`base = "empty"`) knows what it must keep. Every line has kit evidence.

## Known facts

- The kit and sample mods are git-ignored; read-only copies are inside your worktree: `target/ref/kit/` (the kit's .py files = `Module_system 1.171/`), `target/ref/Persistent-Kingdoms/`, `target/ref/Diplado/` (Diplado sources under `source/`). The built atlas is `target/uw-staging/atlas.json`. Cite evidence with the original paths (`Module_system 1.171/<file>:<line>`, `ornek-modlar/<mod>/<file>:<line>`).

- The kit (`Module_system 1.171/`, READ ONLY) marks such records with comments like "do not
  change", "hardcoded", "must be first" (e.g. module_troops.py near line 258, module_parties.py
  near 47, module_factions.py near 24 — verify).
- Engine-referenced positions also show in `header_*.py` constants and in mission templates /
  scenes used by the engine (multiplayer, tutorial, main party `p_main_party`, `trp_player`,
  `fac_no_faction`, …). Only write what you find evidence for.
- Background: docs/meclis/yon3/M2-KANIT.md §4, docs/KNOWLEDGE.md (grep D4, D8, D10, hardwired).

## Steps

1. grep the kit for hardwired/hardcoded/"do not"/"must"/"engine" comments in module_*.py.
2. Write kit-meta/hardwired.toml: `[[record]] table = "troops"  id = "trp_player"  position = 0
   reason = "…"  evidence = "module_troops.py:NNN"  certainty = "comment" | "inferred"`.
3. Add a loader + check in crates/uw_atlas or a small test that every `id` exists in the atlas fixture
   or real atlas and every evidence line exists in the kit file.

## How to test

crates/uw_decomp/tests/hardwired_t122.rs: parse the toml; assert ≥1 record; for each record
the kit file named in `evidence` exists and the line number is within the file; ids resolve in the
atlas when `target/uw-staging/atlas.json` exists (skip otherwise, with a printed note).

## Done when

- hardwired.toml with evidence for each line; test green; report lists counts per table.

## Do not

- Never write into `Module_system 1.171/`. Never invent an id: only ids found in the kit.

## Stop and report if

- A test still fails after 5 steps on it.
