What changed

- crates/uw_syntax/src/lib.rs
  - New top-level item `Item::Every { interval: String, body: Block, span }`. The interval is kept as the Python literal the kit's record needs (`24`, `6`, `0.5`), because simple_triggers is `(check_interval, ops)` and the number is raw there; a String also keeps `Item`'s `Eq`.
  - New `Parser::every_interval` (next to `save_value`): `day` → "24", `hour` → "1", `<N> hours` → the number as written. The lexer has no float token, so `0.5` arrives as `Int(0) Dot Int(5)`; the helper joins them itself ("0.5"). Anything else (`every week`, `every 6 sheep`, `every 0.` with no digits) is `E0100_UNEXPECTED` with a help line naming the three forms.
  - `Parser::file` gains the `every` arm (builds the item with `self.block(…)`, so the body is an ordinary block), and the "expected `mod`, …" message now lists `every`.
