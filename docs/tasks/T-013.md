# T-013: Golden tests for uw build output (.uw -> generated module_*.py)

Status: ready
Budget: $0.80
Steps: 200

## Goal

A golden-test setup so every language feature added later has a test that reads like documentation:
`crates/uw_cli/tests/golden/<case>/input.uw` + `expected/<module>.py`; the test parses, checks and
emits (no kit, no Python, no game) and compares the generated wrapper text exactly.

## Known facts

- Pipeline: `uw_syntax::parse` -> `uw_check::check(atlas, sources, fallback_name)` ->
  `uw_emit::emit(&checked, debug)` returning `Emitted { files: Vec<OutFile{name,text}> .. }`
  (crates/uw_emit/src/lib.rs:18-25, 117). See how `crates/uw_cli/src/build.rs` calls them.
- Tests need an atlas; use or extend a small fixture in `crates/uw_cli/tests/fixtures/` (look at the
  existing ones and at `uw_check` tests for what `check` needs: ops, menus, hooks).
- Normalise `\r\n` to `\n` before comparing.

## Steps

1. Test runner `crates/uw_cli/tests/golden.rs`: for each dir under `tests/golden/`, run the pipeline,
   compare each expected file; on mismatch print a unified-ish diff. Env `UW_BLESS=1` rewrites the
   expected files (document this in a comment at top of golden.rs).
2. Cases: `override_menu_enter` (praven_start-like), `hook_append` (`on game.start`), `debug_menus`
   (same as first with debug on: put `debug` marker file in the case dir), and one error case dir
   `error_unknown_op` with `expected/error.txt` holding the error text.

## How to test

`cargo test -p uw_cli --test golden` passes; changing one char in an expected file makes it fail
(check this by hand once, then restore).

## Done when

- Tests pass; no warnings.

## Do not

- Change uw_syntax, uw_check, uw_emit source (tests only), build.rs logic.

## Stop and report if

- The pipeline cannot run without the kit/Python.
