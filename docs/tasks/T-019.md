# T-019: Golden tests for grammar 2

Status: ready
Budget: $1.00
Steps: 200

## Goal

Golden cases (crates/uw_cli/tests/golden/, runner golden.rs, `UW_BLESS=1` to write expected files) for
every grammar-2 form, so each one reads like documentation and breaks loudly if output changes.

## Known facts

- Forms and their meaning: docs/kilavuz/UW_KILAVUZU.md sections 3.5-3.8 and
  docs/meclis/gramer-2-oneri.md. A full working example: examples/menu_demo/menu_demo.uw (it passed
  the real kit build).
- The golden atlas fixture crates/uw_cli/tests/fixtures/atlas_golden.json is small: extend it with what
  the cases need (a menu with options shaped like module_game_menus.py:20-32, the ops used, e.g.
  troop_add_gold, display_message, party_is_active, store_*, val_*, try_*), copying the shape of the
  entries already in it. Use only real Native names (from the example or the kit), never invented ones.

## Steps

1. Cases: `assign_and_arith`, `if_else_chain`, `and_or_not` (one this_or_next group and one flag case),
   `menu_text_and_options` (text, option with when + after, change option, remove option),
   `new_menu`, and error cases `error_option_exists` (E0206), `error_option_unknown` (E0207),
   `error_local_temp` (E0210).
2. Write expected files with `UW_BLESS=1`, then READ each one and check it by hand against the guide.

## How to test

`cargo test -p uw_cli --test golden`; `cargo test --workspace` green.

## Done when

- Tests pass, no warnings.

## Do not

- Change source code outside tests/ and the fixture (if output looks wrong, finish blocked and say why).
