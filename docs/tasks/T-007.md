# T-007: load Native's official Turkish texts

Status: ready
Budget: $0.60
Steps: 160

## Goal

Read Warband's official Turkish translation files so the tools can show the Turkish text next to a
Native thing.

## Known facts

- `crates/uw_cli` is a binary crate. Add ONLY one `mod tr;` line to `src/main.rs`; no wiring.
  `#[allow(dead_code)]` on pub items not yet used; no build warnings.
- docs/bilgi/diyaloglar-ve-ceviri.md: `Modules/Native/languages/tr/` has `dialogs.csv`,
  `game_menus.csv`, `troops.csv`, ... one entry per line `key|text`, keys like `dlga_start:...`,
  `menu_start_game_0`, `mno_start_male`.
- Warband path on this machine: `C:\Program Files (x86)\Steam\steamapps\common\MountBlade Warband`.
  Read only; never write there.

## Steps

1. New file `crates/uw_cli/src/tr.rs`: `pub fn load_dir(dir: &Path) -> std::io::Result<HashMap<String,
   String>>`: every `*.csv` directly in dir, sorted by file name; each line split at the FIRST `|` into
   key and text; strip a UTF-8 BOM and trailing `\r`; skip empty lines and lines without `|`; read bytes
   and decode lossily; when a key repeats, keep the first value.
2. `pub fn default_dir() -> Option<PathBuf>`: the path above + `Modules\Native\languages\tr` when it is
   a directory.

## How to test

Unit tests write two csv files into a fresh folder under `std::env::temp_dir()` (name with the process
id; remove it at the end): BOM on the first line, CRLF endings, a text containing `|`, an empty line, a
line without `|`, one key in both files. Assert the exact map. default_dir test: if Some, the path ends
with `tr`.

## Done when

- Tests pass; no build warnings.
