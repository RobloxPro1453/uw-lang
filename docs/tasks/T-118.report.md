# T-118 raporu — Mod kipinde alan yazımı (`override <tür> <kayıt> { alan değer }`)

## Ne yapıldı

Yama kipinde (uw.lock'suz klasör) artık **var olan bir Native kaydın alanları değiştirilebiliyor**:

```
override troop swadian_recruit {
    agility 18
}
```

Kayıt **listede yerinde kalır** (numarası kaymaz); yalnız yazılan alanlar değişir. Alan denetimi,
`troop … like …` yeni-kayıt yolunun kullandığı **aynı şema makinesinden** geçer (`record_copy`,
`uw_check:1039`); bilinmeyen alan/değer `dosya:satır` ile hata verir.

## Dosyalar

| Dosya | Değişiklik |
|---|---|
| `crates/uw_syntax/src/lib.rs` | `Member::Field(FieldValue)` eklendi; `record_body` içinde menü anahtarı olmayan satır artık alan olarak ayrıştırılıyor |
| `crates/uw_check/src/lib.rs` | `Action::ReplaceRecord { value }` eklendi; `Item::Override` yolunda kayıt dalı (şema denetimi, kayıt çözümleme, yinelenen denetimi); menü ve `new menu` döngülerine "menü alan almaz" dalı |
| `crates/uw_emit/src/lib.rs` | `ReplaceRecord` → `{var} = _uw.replace_entry({var}, "<kayıt>", <yeni kayıt>)` |
| `crates/uw_check/src/lib.rs` (test) | 2 yeni test + eski "not in UW yet" testi güncellendi |
| `crates/uw_syntax/src/lib.rs` (test) | 1 yeni test (gövde alanları) |
| `crates/uw_emit/src/lib.rs` (test) | 1 yeni test (`replace_entry` çıktısı) |

`py/uw_runtime.py` **değişmedi**: `replace_entry` (satır 105) ve `find` (satır 38) zaten vardı —
meclisin dediği gibi eksik olan "özellik" değil, **bağlanmamış ilkeldi**.

## Doğrulama

- `cargo build --workspace` → yeşil.
- `cargo test --workspace` → **443 geçti, 0 hata** (66 suite).
- **Uçtan uca (gerçek kitle):** yama kipinde bir klasörde `override troop swadian_recruit { agility 18 }`
  ile `uw build` → **32 dosya, 30 sn, hatasız**. Aynı klasör override'sız da derlendi; iki çıktı
  karşılaştırıldı: **32 dosyadan yalnız `troops.txt` farklı, o da yalnız 1 satır** —
  `swadian_recruit`'in satırı `7 5 4 4 4` → `7 18 4 4 4`. Başka hiçbir satır değişmedi.

## Bulunan iki tuzak (KNOWLEDGE'a yazıldı)

1. Atlas'ta bir kaydın `value` alanı düz dizi değil, **`{"list": [...]}`** biçiminde.
2. `uw_runtime.find` listeyi kaydın **çıplak adıyla** arar (`swadian_recruit`), kit referansıyla değil
   (`trp_swadian_recruit`). İlk denemede kit referansı yazıldı ve kit "no entry named" dedi.

## Dürüst sınırlar (v1)

- Yalnız `copy_table`'ın tanıdığı türler: **`troop`, `town`, `castle`, `village`, `party`**. Başka tablolar (item, faction, presentation …) için eski hata (`E0201_NOT_YET`) kalır; onları açmak P4'ün işi.
- Yalnız **alan** yazılır; kaydın gövdesine işlem bloğu ekleme (menüdeki `on enter` gibi) kayıtlarda yok.
- `like`'ın **bileşik dünya** çözümlemesi (P4) bu işin dışında; `override` mevcut Native kaydı hedefler.
- Ölçüm: bu iş C1'in "%19 alan yazımı" boşluğunun **ilk** parçası; kapsam oranı P6'da yeniden ölçülmeli.
