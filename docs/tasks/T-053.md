# T-053: Lowering of `require` / `attempt` / `for`, and checking of `for` (P2)

Status: ready
Budget: $1.50
Steps: 350

## Goal

The lower IR nodes `Stmt::Require`, `Stmt::Attempt`, `Stmt::For` (crates/uw_lower/src/lib.rs, read their doc
comments) turn into the exact Native operations, and uw_check turns `uw_syntax::Stmt::For` into
`uw_lower::Stmt::For`. Today both places are `unimplemented!` stubs marked T-053.

## Known facts

- Lowering:
  - `Require { cond }` → the condition's operations inline, exactly as an `if` head lowers its condition
    (reuse that code: `and` = sequence, `or` = `this_or_next|` chain, `not` → `neg|` / inverted compare).
  - `Attempt { arms }` → `try_begin`, arm 1, `else_try`, arm 2, …, `try_end` (one arm: no `else_try`).
  - `For { op, var, args, body }` → `op(var, args…)`, body, `try_end`.
  - The kit names: `try_begin` = 4, `else_try` = 5, `try_end` = 3, loops `try_for_range` = 6 …
    (Module_system 1.171/header_operations.py:16-29); use the atlas op table, never literal numbers.
- Checking (crates/uw_check/src/lib.rs, the `Stmt::For` arm): `op` = `"try_for_" + kind`; it must exist in
  the atlas op table, else an error listing the existing `try_for_*` ops (from the table, not a list in
  code); the loop variable must be `$global` or `:local`; args checked like call args; body checked with
  `self.stmts`. Arg count: same rule the checker applies to calls.
- `Require` and `Attempt` checking is already written (same file).

## Steps
