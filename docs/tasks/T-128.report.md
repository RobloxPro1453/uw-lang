**Modelled (record-backed)**
- `troop_get_type` = low nibble of `troop_flags` (`troop_type_mask` 0x0f; docs/bilgi/anlam/asker-ve-birlik.md:91).
- `store_troop_faction` and `store_faction_of_troop` (one opcode 2173, both names matched) read the `faction` cell; `troop_set_faction` writes it.
- `store_attribute_level` (dest, troop, attribute) = byte `8*attr` of `attributes`; `store_character_level` = top byte (shift 32) of `attributes`; `store_skill_level` (dest, skill, troop) = 4 bits at `4*skill` of `skills`. Bit layout and counts come from kit-meta/records/troops.toml and header_troops.py/header_skills.py, cited in the file.
- `troop_is_hero` = `troop_flags & tf_hero`; unknown flags are counted instead of deciding the condition.
- `troop_get_upgrade_troop` reads `upgrade_1`/`upgrade_2`, returning -1 for the record's 0 ("no target") padding per header_operations.py:635.
- `troop_set_age` writes an `age` cell. The troop record has no age field, so this is a run-only cell: the trace shows Native's value, the record printer never shows it.
- Inventory-changing ops (`troop_clear_inventory`, `troop_add_item`, `troop_add_items`, `troop_remove_items`, `troop_add_merchandise`) write the `inventory` cell as **unknown** — an item list is not a number and merchandise is engine-random. `troop_remove_items` also sets reg0 unknown, because it puts the items' cost there (header_operations.py:622).
- `troop_set_name` writes the `name` cell as unknown (record text, not a number).

**Explicitly left unknown (reason in the unknown-op name)**
- `troop_equip_items` / `troop_has_item_equipped` — equipment is engine state; a record keeps only the item list.
- `troop_ensure_inventory_space` — inventory capacity is engine state.
- `troop_raise_attribute` — the new byte is computable but whether the engine clamps it is undocumented (docs/bilgi/anlam/oyuncu-varliklari.md:140).
- `store_troop_gold` — gold is not a troop record field.
- `store_character_level` / `store_skill_level` called without the optional troop operand — no documented default troop, so the result stays unknown instead of guessing `trp_player`.
