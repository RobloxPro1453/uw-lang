# T-102: Easy dialogs: `dialog king_harlaus first_meeting { }` (easy-language §4)

Status: ready
Budget: $2.00
Steps: 500

## Goal

```
dialog king_harlaus first_meeting {
    harlaus: "Who are you, stranger?"
    player: "Just a traveller."                      -> end
    player: "I wish to serve you." when player.renown >= 300 {
        say("@He nods.")
    }                                                -> end
}
```
compiles to Native dialog lines that make this the king's greeting the first time you meet him.

## Known facts

- Read docs/bilgi/anlam/diyaloglar.md first: a line has 7 fields (§1), scan order = first match wins and
  NPC lines are order-sensitive (§2, §9), states (§3), talk partner (§4), "first meeting" check
  `(neq, "$g_talk_troop_met", 0)` (§5), ending (`close_window`, §6), player choices (§7).
- Game names resolve troops (`king_harlaus` → trp_kingdom_1_lord); fns/objects/save work in blocks (uw_check).
- uw_runtime has helpers to add records; dialogs must go BEFORE Native's generic lines for the same state
  or they never fire (§9).

## Steps

1. Syntax: `dialog <troop> <name> { <speaker>: "text" [when cond] [{ block }] [-> end | -> <line label>] … }`
   (first line = NPC opening; `player:` lines = choices).
2. Lower to dialog records: opening line `anyone|...` with condition talk troop == <troop> (and first meeting
   for `first_meeting`), unique states `uw_<name>_<n>`; insert before Native's lines (add a uw_runtime
   helper with a python test if none can insert at the front).
3. Golden crates/uw_cli/tests/golden/dialog_first_meeting/. Add a CHECKUP item (Turkish, step by step) for
   the owner to try it in game.

## How to test

The golden fails if any of the 7 fields, the states or the insert position differ.
