# T-076: The record header uses the game name (P5b)

Status: ready
Budget: $1.00
Steps: 250

## Goal

In a project folder a record starts with the name the modder knows: `faction swadia {`, `party praven {`,
`troop count_klargus {` (the `id kingdom_1` line stays and is still what the kit gets).

## Known facts

- Game names: crates/uw_decomp/src/names.rs; `Atlas::game_name(reference)` / `Atlas::reference_for(name)`
  (crates/uw_atlas/src/lib.rs, `set_game_names`). A reference is `<ref_tag>_<record id>` (`fac_kingdom_1`);
  `atlas.tables[table].ref_tag` holds the tag.
- Header printed in `print_record` (crates/uw_decomp/src/records.rs ~line 321, `record_id`), read in
  `parse_record` (~line 512); the parsed id is what project load/verify match records by.
- `uw new` installs names before printing (crates/uw_cli/src/new.rs `export_project`); `uw new --check`
  and `uw build-project` install them from names.uw before parsing.

## Steps

1. print_record: when an atlas is given and it has a game name for `<tag>_<id>` of this record, print that
   name as the header instead of the id.
2. parse_record: when an atlas is given and the header is a game name whose reference belongs to
   `schema.table` (same tag), return the bare record id (reference minus `<tag>_`) as the id.
3. A header that is neither the id nor a game name of this table stays the error it is today.

## How to test

Add crates/uw_decomp/tests/header_t076.rs (skip if the atlas is missing): install `names::derive` into the
atlas, print_with_blocks the factions entry `kingdom_1` → text starts with `faction swadia {`; parse it back
→ id `kingdom_1` and value equal to the atlas value. Plus: without names installed the header is `kingdom_1`.

## Done when

- `uw new` then `uw new --check` on a fresh folder: 12815/12815 exact (put the output in the report).
- Build and tests pass.

## Do not

- Change file names/paths (crates/uw_decomp/src/project/layout.rs) or kit-meta/records/*.toml.

## Stop and report if

- Load/verify match records by something other than the parsed id. A test still fails after 5 steps.
