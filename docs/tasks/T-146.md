# T-146: infrastructure scan - 09-between-empires

Status: ready
Budget: $1.20
Steps: 200

## Goal

Evidence for the UW language design (owner, VISION "2026-11-21 akşam": MS = assembly, UW = Python).
Find the GENERAL infrastructure that the mod `09-between-empires` had to build by hand because the Module System
lacks it (example kinds: "is a key held", HUD/presentation framework, timers/cooldowns, persistent
per-object data, lists/arrays emulated with slots, string building, custom events, options menu).
Mod-specific game ideas (a new faction, a quest story) are NOT infrastructure; skip them.

## Known facts

- The mod's sources are copied read-only into your worktree: `target/ref/mods/09-between-empires/` (Python
  Module System files; the folder name may contain spaces or sub-folders such as `ModuleSystem/`).
- The plain kit is at `target/ref/kit/` (Module System 1.171). Use it to tell "added by the mod"
  apart from "already in Native": a script/trigger/presentation that also exists in the kit is Native.
- Cite evidence as `mods/09-between-empires/<path>:<line>`.

## Steps

1. Find the mod's `module_*.py` files. Diff mentally against the kit: look at scripts, simple
   triggers, mission template triggers, presentations and header/constant files the mod ADDED.
2. Group what you find into reusable infrastructure patterns. Use these category codes when they
   fit: INPUT, TIMER, STATE, COLLECTION, UI, TEXT, MATH, AGENT, NETWORK, EVENT, AI, DEBUG, CONFIG,
   BUILD (Python-side tools/code generators). Use `OTHER:<short name>` otherwise.
3. Write `docs/bilgi/altyapi/09-between-empires.md` (at most 120 lines):
   - one line about the mod (what kind of mod, roughly how many scripts it adds);
   - a table: `| # | category | pattern (generic, one line) | evidence (file:line, 1-3) | approx lines | times reused |`
     with 8-25 rows, most important first;
   - "Top 5 things a language should give built in" - one line each, generic wording, no mod names;
   - "Native code the mod changed" - which Native scripts/menus it overrode, at most 10 lines.

## How to test

Doc-only task: no code changes. `cargo build --workspace` must still pass. Every row needs at
least one `file:line` that really exists in `target/ref/mods/09-between-empires/`.

## Done when

- `docs/bilgi/altyapi/09-between-empires.md` exists with the table and the two lists.

## Do not

- Do not edit code, `target/ref/` or anything outside `docs/bilgi/altyapi/09-between-empires.md`.
- Do not copy mod code longer than 3 lines into the doc (licenses are mixed): describe it.
- Do not invent: if a pattern has no evidence line, leave it out.
