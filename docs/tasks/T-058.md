# T-058: Readable record fields, core: `ref`, `flags`, `bits`, `list` types (P5)

Status: ready
Budget: $2.50
Steps: 500

## Goal

Record fields can be typed so they print readably and still read back to the identical atlas value:
`faction fac_kingdom_1` instead of `3`, `flags [tf_hero, tf_male]` instead of `3145728`,
`attributes {str 21, agi 8, int 4, cha 5, level 25}` instead of one huge integer. Decision:
docs/arsiv/meclis-yon1-yon2/YON2-KARAR.md §2.4 (names only from kit constants; unknown bits never dropped).

## Known facts

- Core: crates/uw_decomp/src/records.rs (`Value`, `Field.ty`, `Schema::from_toml` accepts only `raw` today,
  `print_with_blocks`, `parse_with_blocks`, `roundtrip_table_with_blocks`, `record_difference`).
- Atlas: `atlas.constants` (kit constants: name, value, module, line), `atlas.tables[t].entries[i].id`
  (index ↔ id). Kit layouts (read-only): Module_system 1.171/header_troops.py (attribute/skill/wp bit
  positions, `level()` uses `bignum`), header_items.py, header_parties.py, header_common.py.
- Measures: `uw roundtrip` (records 12815/12815 must stay), `uw build-project --native-check` and
  `uw new` + `uw build-project <dir> --compare-native --no-install` (32/32 must stay).

## Steps

1. `Value::Struct(Vec<(String, Value)>)`, printed inline `{a 1, b 2}`, parsed back.
2. Field types (string `ty`, plus optional tables in the field):
   - `raw` (as today).
   - `ref:<table>`: integer index → that table's atlas id (`fac_kingdom_1`); reading the id gives the index.
     A value that is not a valid index (negative, too big, not an int) stays a plain integer.
   - `flags:<prefix>[,<prefix>…]`: integer → list of kit constant names with those prefixes. Optional
     `enums = [{ mask = <int or constant name>, prefix = "..." }]`: `value & mask` must equal exactly one
     constant with that prefix (then it is listed and removed). Remaining bits: single-bit constants with
     the prefixes. Anything left → a `rest <n>` element. Zero → `[]` (or the one constant whose value is 0
     when the field says `zero = "<name>"`).
   - `bits`: `[[fields.parts]] name, shift, width, source` (+ optional `ty` for a part, e.g. a ref);
     prints `{name value, …, rest <n>}` (`rest` only when bits remain outside the parts).
   - `list:<type>`: a list/tuple whose elements have that type (shape kept).
   - Every decode is checked: encode(decode(v)) must equal v, else the field prints raw (never wrong).
3. Pilot: kit-meta/records/troops.toml → `faction` as `ref:factions`, `attributes` as `bits` (str, agi,
   int, cha, level: positions from header_troops.py, cite lines). Leave the other troop fields raw.
4. Coverage line in `uw roundtrip` records block: per table `typed N/M fields, raw-rest K values`.
5. Tests: each type both ways on tiny values; an unknown bit lands in `rest`; a bad ref stays an int; the
   real atlas (skip if missing): troops 1072/1072 exact with `faction fac_` and `attributes {str` in text.

## How to test

Round-trip tests compare JSON values exactly; the real-atlas test fails if a troop changes or the pilot
fields still print raw.
