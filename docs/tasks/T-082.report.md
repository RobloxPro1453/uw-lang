Decisions worth knowing
- Temporary names: statement-path object words use `:_uw_getN` / `:_uw_valN` on purpose — `uw_lower` numbers its own temporaries `:_uw0…` from 0 in every block, and the two can land in the same block (`:_uw0` twice would be a silent collision); the extra word keeps them apart. In the `when` path a single counter is shared with `uw_lower` via `lower_from`, so numbering stays tight there.
- `*=` `/=` `%=` have no verb in the spec; I did not guess one. They report E0216 "`player.gold` has no `*=` form" with the help "a dotted word takes `=`, `+=` and `-=`". Report if you want `.mul/.div/.mod`.
- Small known hole: to let a get fill its temporary through a fn parameter, `Ctx::local` accepts the exact `:_…` temp names lowering generated in that file. A user who types one of those names in the same file would not get E0210; every other `:_` name is still rejected (the `error_local_temp` golden is unchanged and passing).
- Out of scope, as the spec limits it: dotted words as arguments of a Native call (`display_message(player.x)`) are still rejected; a dotted word written directly as a call (`player.gold.add(5)`) does work because it resolves to the same fn table.
