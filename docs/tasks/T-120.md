# T-120: `uw coverage` v1 — how much of Module System the language really reaches (YÖN-3 P0)

Status: ready
Budget: $3.00
Steps: 300

## Goal

`uw coverage` prints one honest number: of everything Module System can do, how much UW can write
today, proven by compiled golden tests. `--json` gives the same as data. This is the project's
progress meter (docs/meclis/yon3/KARAR.md §6, docs/meclis/yon3/M4-OLCUM.md).

## Known facts

- The kit and sample mods are git-ignored; read-only copies are inside your worktree: `target/ref/kit/` (the kit's .py files = `Module_system 1.171/`), `target/ref/Persistent-Kingdoms/`, `target/ref/Diplado/` (Diplado sources under `source/`). The built atlas is `target/uw-staging/atlas.json`. Cite evidence with the original paths (`Module_system 1.171/<file>:<line>`, `ornek-modlar/<mod>/<file>:<line>`).

- Inventory comes from the atlas (`target/uw-staging/atlas.json`, loaded with `uw_atlas::from_path`;
  find how other commands locate it, e.g. crates/uw_cli/src/words.rs or check.rs): `atlas.tables`
  (record tables), `atlas.ops` (header_operations), hook kinds = constants named `ti_*` (exclude
  `ti_once`, `ti_never`).
- Golden tests live in crates/uw_cli/tests/golden/<name>/ with `input.uw` and `expected/*.py`;
  names starting `error_` are error tests.
- UW comments are `//`.

## Steps

1. New module crates/uw_cli/src/coverage.rs + `coverage` subcommand in main.rs.
2. Cells: table grid = every record table × {new, like, override, disable, hook}; hook grid = every
   `ti_*` hook; op grid = every op name.
3. A cell is filled ("silver") only when a golden test's input.uw has a line
   `// covers: <cell>` (cells written `<table>.<action>`, `hook.<ti_name>`, `op.<name>`) AND the test
   is not an `error_` test AND its expected output contains that table's module file (for table
   cells) or the op/hook name (for op/hook cells). A tag that fails this check is listed as
   "tag without proof" and does not count.
4. "Gold" = cell also listed in docs/coverage-gold.txt (one cell per line, owner's in-game proofs;
   create the file empty with a header comment).
5. Output: per-grid filled/total and percent, overall weighted 0.5 table / 0.3 hook / 0.2 op,
   then the empty cells (table grid only, unless `--all`). `--json` for all of it.

## How to test

crates/uw_cli/tests/coverage.rs: build a temp golden dir with two tests — one valid tag, one tag
whose expected output lacks the table → assert filled = 1 and "tag without proof" = 1. Plus a test
that the cell totals equal the counts read from the fixture atlas (no hard-coded numbers).

## Done when

- `uw coverage` runs on the real repo and prints numbers; record them in the report.
- Build and tests pass.

## Do not

- Do not edit existing golden tests (another task adds tags). Do not touch crates/uw_check.

## Stop and report if

- The atlas has no way to tell hook constants from others.
- A test still fails after 5 steps on it.
