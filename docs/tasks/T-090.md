# T-090: `uw explain` and `uw browse` know game names

Status: ready
Budget: $0.80
Steps: 200

## Goal

`uw explain praven`, `uw explain swadia`, `uw explain count_klargus` work like `uw explain p_town_6`, and the
answer shows the game name next to the kit id (`p_town_6 (praven)`).

## Known facts

- Names: `uw_decomp::names::derive(atlas)`, `Atlas::set_game_names`, `game_name`, `reference_for`.
- explain/browse/graph load the atlas via `crate::load` (crates/uw_cli/src/model.rs; lookup ~line 340).

## Steps

1. When loading the model for explain/browse/graph, install the derived names (or the names.uw of the
   working folder if it has one, via `crate::new::install_names`).
2. Lookup accepts a game name; printed entries show `(game name)` after the id when there is one.
3. Tests in crates/uw_cli/tests/explain.rs (fixture atlas): `praven` resolves to `p_town_6`.

## How to test

The new test fails if a game name is not found or the `(praven)` mark is missing.

## Done when

- Build and tests pass.

## Do not

- Touch crates/uw_check, crates/uw_syntax, crates/uw_decomp/**, crates/uw_cli/src/build*.rs, roundtrip.rs.

## Stop and report if

- Installing names changes any existing explain output besides the added mark. 5 failed steps.
