What I changed (all new files, nothing existing touched; uw_syntax / uw_check / uw_emit / build.rs untouched):
- `crates/uw_cli/tests/golden.rs` — the runner. It walks the sorted folders under `tests/golden/`, reads `input.uw`, treats the presence of a `debug` marker file as `emit(..., debug = true)`, and runs exactly `uw_syntax::parse` -> `uw_check::check(atlas, sources, "golden")` -> `uw_emit::emit`. The generated wrappers are compared with `expected/<module>.py`; `uw_runtime.py` is filtered out (it is just a copy of py/uw_runtime.py). A case whose `expected/` holds `error.txt` is an error case: the rendered `Diagnostic::render` text (joined with newlines) is compared instead, and the case fails if the pipeline unexpectedly succeeds. `\r\n` is normalised to `\n` on both sides and one trailing newline is ignored, so a CRLF checkout or an editor adding the final newline does not fail. On mismatch the failure prints a small line diff (`-` expected, `+` actual, capped at 20 lines). `UW_BLESS=1` rewrites the expected files from the current output (documented in the module comment at the top of golden.rs). The test also fails when a success case generates no wrappers, so no case can pass vacuously.
