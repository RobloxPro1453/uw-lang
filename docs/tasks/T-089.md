# T-089: Translations follow renames (P3b-dil)

Status: ready
Budget: $1.30
Steps: 350

## Goal

The owner renamed Praven in a project and the Turkish game still showed "Praven Şehri": the installed mod
copies Native's languages/ and `languages/tr/parties.csv` line `p_town_6|Praven Şehri` overrides the name
(docs/bilgi/proje-kipi-deneyi.md). After this, a project owns its translations and a renamed record's
translation line is dropped (so the new name shows) with a warning naming the record and the file.

## Known facts

- `uw new` export: crates/uw_cli/src/new.rs; project build/install: crates/uw_cli/src/build_project.rs.
- Language files: `<Warband>/Modules/Native/languages/<lang>/*.csv`, lines `id|text` (find the install
  folder the same way the build already does). These are TaleWorlds files: they go to the user's project
  folder and the installed mod only, never into this repository.

## Steps

1. `uw new`/`uw create`: copy Native's languages/ into `<project>/languages/` (unchanged). Missing install:
   skip with one line, not an error.
2. build-project install: copy the project's languages/ (not Native's) into the installed mod. For every
   record whose `name` (and `plural_name` for troops) differs from Native's, leave out that record's lines
   (`p_town_6|…`, `p_town_6_pl|…` style as the files use) from the installed copy and print
   `translation dropped: p_town_6 (languages/tr/parties.csv): renamed in the project`. The project's own
   files are never changed.
3. Tests with a temp project + temp fake install (no real game needed).

## How to test

The test builds a tiny languages folder, renames one record, and asserts the installed copy lacks exactly
that line and the project copy still has it.

## Done when

- Build and tests pass; `uw new --check` still exact.

## Do not

- Touch crates/uw_syntax, crates/uw_check, crates/uw_decomp/src/records.rs, lib/**. Never write into the
  game's Native folder.

## Stop and report if

- The csv id format differs from `id|text` for some file (list them). 5 failed steps.
