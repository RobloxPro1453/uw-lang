## Goal

A Turkish knowledge page `docs/bilgi/anlam/hareket-ve-harita.md` that tells how Native does these things, so the easy
UW words (docs/arsiv/meclis-yon1-yon2/kolay-dil-taslak.md) can be built on proven Native operations:
moving the player or a party on the world map (near a place, to a position), opening the map / a menu / a scene, entering a town, current location of the player.

- Kit (read-only): `Module_system 1.171/` (header_operations.py has every operation with a comment;
  module_scripts.py, module_game_menus.py, module_dialogs.py, module_simple_triggers.py … show real use).

  [İDDİA] if not proven. Motor behaviour that only a game test can prove is marked [DENEY GEREK].
