# T-113: Names per language (`name_tr "…"`) and a project rule for translation suffixes

Status: ready
Budget: $1.50
Steps: 400

## Goal (owner's decision, 2026-11-16: translations must be flexible)

1. Any record with a `name` may also say `name_tr "Adam Siken"` (any language folder code: `name_de`,
   `name_es`, …). The build then writes that text for that record into the installed
   `languages/<code>/<table>.csv` line, whatever the old translation said.
2. Project rule in uw.toml, e.g.
   ```
   [languages.tr]
   strip_suffix = [" Şehri", " Kalesi"]
   ```
   removes those endings from that language's translations at build (owner wants "Praven", not
   "Praven Şehri"). `add_suffix` works the other way. Nothing silent: the build prints a Turkish summary
   ("tr: 22 çeviriden ' Şehri' kaldırıldı") and, with `--verbose`, each line.
3. Default (no field, no rule) = today's behaviour; an unchanged project stays byte-identical (32/32) and
   the installed languages folder unchanged.

## Known facts

- Languages are installed by crates/uw_cli/src/build_project.rs `install_languages` /
  `copy_languages_filtered` (project `languages/` or Native's, filtered by rules). Extend that path.
- Records are loaded in crates/uw_decomp/src/project/load.rs; `owner` (T-103) is a project-only field that
  is taken out before schema parsing (`take_owner` in project/mod.rs) — do `name_<code>` the same way.
- The CSV key of a record's name: look at a real Native CSV (e.g. `<Modules>/Native/languages/tr/parties.csv`
  lines like `p_town_1|Praven`); verify the key form per table from real files, never guess. uw.toml is read
  in build_project.rs (find the existing reader).
- Some Native CSVs are not UTF-8 (es/party_templates.csv): read lossily, never fail (see rename.rs fix).

## Steps

1. Loader: collect `name_<code>` per record (id + table), strip before parsing; unknown code letters only.
2. Install: apply suffix rules, then per-record names (names win). Turkish summary.
3. Tests (temp dirs, no game needed): name_tr overrides a line, strip_suffix removes it, add_suffix,
   unchanged project leaves the CSV byte-identical, non-UTF-8 file survives.

`uw build-project <tmp> --compare-native --no-install` (32/32).
