# T-111: `uw rename` also offers the other texts that contain the old name (owner's Praven test)

Status: ready
Budget: $1.00
Steps: 300

## Goal

After renaming Praven to "Adam Siken", the old name stayed in other texts ("join a caravan to Praven",
"Merchant of Praven", translations "Praven Şehri"). Now:

```
uw rename praven "Adam Siken"
  town_1 adı değişti.
  "Praven" şu metinlerde de geçiyor (değiştirilmedi):
    1  menus/start_phase_2.uw:14   "...join a caravan to Praven, in the..."
    2  troops/merchants.uw:3       "Merchant of Praven"
    3  languages/tr/parties.csv:7  "Praven Şehri"
  Hepsini değiştirmek için:  uw rename praven "Adam Siken" --texts all
  Seçerek:                   uw rename praven "Adam Siken" --texts 1,3
```

`--texts` replaces the old name (whole word) only in the chosen texts; a translation keeps its pattern
("Praven Şehri" → "Adam Siken Şehri"). Nothing is changed silently; every change is printed. The
existing backup + `--undo` (T-094 follow-up, crates/uw_cli/src/rename.rs) covers these files too.

## Known facts

- `uw find` (T-105, crates/uw_cli/src/find.rs) already finds whole-word hits in .uw texts and
  languages CSVs with file:line; reuse it (make a shared function), do not write a second matcher.
- rename.rs: backup before writing, `--undo` restores. Its tests must stay green.
- Owner decision: special names (a merchant's title) are never changed without being chosen — hence the
  numbered list. A per-language name (`name_tr "…"`) and bulk suffix edits are later tasks, not this one.

## Steps

1. After the record rename, list other hits (numbered, stable order) and the two hint lines.

3. Tests in crates/uw_cli/tests/ (temp project with a menu text, a troop name and a tr CSV): listing,
   `--texts 2` changes only that one, `--undo` restores all, unchanged when no flag.
