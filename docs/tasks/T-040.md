# T-040: Record schemas: strings, menus (P1)

Status: ready (start only after T-030 is merged)
Budget: $1.00
Steps: 250

## Goal

Every record of these atlas tables prints as UW record text and parses back identical:
strings, menus.
Decision: docs/arsiv/meclis-yon1-yon2/YON2-KARAR.md §2. Round 1 is RAW (every field `ty = "raw"`).

## Known facts

- Core and the pilot schema exist after T-030: crates/uw_decomp/src/records.rs,
  kit-meta/records/factions.toml (copy its layout).
- Field order and meaning: the header comment of `Module_system 1.171/module_<table>.py` (menus are in
  module_game_menus.py, postfx in module_postfx.py; the atlas gives each table's `module`). Read-only.
- Kind word = the singular of the table in English as the kit file names it (troop, item, party, scene_prop …);
  if unsure, use the table name without a trailing "s".

## Steps

1. For each table write `kit-meta/records/<table>.toml`: kind, id_prefix (from atlas `id_prefix`), fields
   with snake_case names from the kit comment and `source = "<file>:<line>"`. A position with no kit comment
   is `field_<n>`. Optional trailing fields (e.g. item triggers) `optional = true`. Never invent a name.
2. Add one real-atlas test per table in the NEW file crates/uw_decomp/tests/records_t040.rs (skip if atlas missing): all records exact. Other lanes run at the same time: never edit a file another lane may edit.
3. If a table fails, fix the schema; if the core is wrong, finish as blocked and describe the core bug.

## How to test

Per-table test asserts `exact == records` and `failed == 0` from `roundtrip_table`; it fails if a field is
missing, extra values are dropped or a value changes.

## Done when

- Every listed table is exact on the real atlas; report gives each table's record count.
- Workspace tests green.

## Do not

- Touch any file except kit-meta/records/<these tables>.toml and crates/uw_decomp/tests/records_t040.rs. Core bugs: report, do not fix (other lanes share it).

## Stop and report if

- A kit comment does not match the atlas value count and you cannot tell which is right.
- A test still fails after 5 steps on it.
