# T-034: `uw roundtrip` reports records (P1)

Status: ready (start only after T-030 is merged)
Budget: $1.00
Steps: 200

## Goal

`uw roundtrip` also measures records: one line per table with a schema (`records N, exact N, failed N`),
a TOTAL records line, the first failures, and writes `target/uw-native/records/<table>.uw` (every record's
text). Tables without a schema are listed as `no schema`.

## Known facts

- Command: crates/uw_cli/src/roundtrip.rs (ops measure, writes target/uw-native/*.uw).
- Core after T-030: `uw_decomp::records::{Schema, roundtrip_table, print}`; schemas in kit-meta/records/.

## Steps

1. Load every kit-meta/records/*.toml, run `roundtrip_table`, print the summary after the ops summary.
2. Write the record texts as above; exit code non-zero if any record fails (same rule as ops).
3. Test with the small fixture atlas: output contains the table line and the TOTAL line.

## How to test

CLI test runs the command on a fixture atlas + temp schema dir and asserts the summary lines and the
written file; it fails if records are not measured or not written.

## Done when

- `uw roundtrip` on the real atlas prints the records block; tests green.

## Do not

- Change the ops measure or its numbers; touch kit-meta/records/ files.

## Stop and report if

- A test still fails after 5 steps on it.
