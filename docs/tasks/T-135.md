## Goal

Every `ui.<part> name { … }` becomes overlays in ONE generated presentation that opens after a mission starts and updates bound values every frame; parts share one property set with defaults (position, size, color, alpha, texture, background, font_size, label, visible; bar adds value/max).

## Steps

1. kit-meta/core/ui.toml (data): each part = list of overlay creations + which properties map to which overlay ops (overlay_set_position/size/color/alpha, create_text_overlay, create_mesh_overlay …); named positions (bottom_left, top_right, center …) as coordinates; defaults.
2. src/lower/ui.rs: build `Presentation uw_hud` (flags prsntf_read_only, prsntf_manual_end_only): on_load creates overlays (ids kept in globals), on_run updates bound expressions (bar fill = size scaled by value/max).
3. Mission triggers: start the presentation after mission start (`ti_after_mission_start`), and a guard trigger that restarts it if it is not active (`is_presentation_active`).
4. Unknown property on a part → error with the list of valid properties.
