# T-005: flow chart export — Mermaid text and a standalone HTML page

Status: ready
Budget: $0.80
Steps: 200

## Goal

The flow from one Native thing (what it leads to) as a picture: Mermaid text, and an HTML page that
draws it in a browser.

## Known facts

- `crates/uw_cli` is a binary crate. Add ONLY one `mod graph_export;` line to `src/main.rs`; no command
  wiring. `#[allow(dead_code)]` on pub items not yet used; no build warnings.
- Model API (`crates/uw_cli/src/model.rs`, read it): `Target`, `model.outgoing(&Target)`,
  `model.label(&Target)`, `model::entry_hint(table, entry)`, `model::short(text, n)`.
- Fixture: `crates/uw_cli/tests/fixtures/atlas_refs.json` (read it).
- Mermaid: `flowchart TD`, node `n0["text"]`, edge `n0 -->|label| n1`. Inside `["..."]` write a double
  quote as `#quot;`, `<` as `#lt;`, `>` as `#gt;`. Line break in a node: `<br/>`.
- The HTML may load Mermaid only from
  `https://cdn.jsdelivr.net/npm/mermaid@10.9.1/dist/mermaid.min.js` and call
  `mermaid.initialize({startOnLoad:true})`; the chart text goes in `<pre class="mermaid">`.

## Steps

1. New file `crates/uw_cli/src/graph_export.rs` with its own breadth-first walk (do not use other new
   files): from a root, follow `model.outgoing` (only `Target::Entry`), up to `max_depth`, at most
   `max_nodes` nodes; ids `n0, n1...` in visit order; one edge per (from, to), label = first op (or no
   label when None).
2. `pub fn mermaid(model: &Model, root: &Target, max_depth: usize, max_nodes: usize) -> String`. Node
   text: label, and `<br/>` + `short(hint, 40)` when there is a hint, escaped as above. If max_nodes cut
   the walk, add a last line `%% truncated`.
3. `pub fn html(model, root, max_depth, max_nodes) -> String`: full page (`<!doctype html>`, utf-8
   meta, `<title>` = root label HTML-escaped, the mermaid block, the CDN script, initialize call).

## How to test

Unit tests with the fixture: mermaid from script `game_start` starts with `flowchart TD`, node and edge
counts are right, an edge carries its op; a hint with `"` is escaped; max_nodes 1 gives one node plus
`%% truncated`; html contains the mermaid text and the exact CDN URL.
