# T-121: `// covers:` tags on the existing golden tests

Status: ready
Budget: $1.00
Steps: 150

## Goal

Every existing golden test says which Module System cells it proves, so `uw coverage` (T-120)
counts today's real reach.

## Known facts

- Golden tests: crates/uw_cli/tests/golden/<name>/input.uw + expected/*.py (25 dirs; `error_*`
  are error tests and get no tag). UW comments are `//`.
- Cell names: `<table>.<action>` (action ∈ new, like, override, disable, hook; table = atlas table
  name such as troops, parties, menus, dialogs, simple_triggers, scripts), `hook.<ti_name>`
  (e.g. hook.ti_on_agent_hit), `op.<op name>` (e.g. op.troop_set_slot).

## Steps

1. For each non-error golden dir, read input.uw and expected/*.py; add at the top of input.uw one
   line per proven cell: `// covers: menus.new`, `// covers: op.party_set_faction`, …
2. Only tag what the expected output really shows (the table's module file is in expected/, the op
   name appears in it). Tag ops only for ops the input writes on purpose, not incidental ones.
3. Do not change anything else in input.uw; the expected outputs must stay byte-identical
   (comments do not reach the output — check by running the golden test).

## How to test

`cargo test -p uw_cli --test golden` stays green (proves comments do not change outputs). Add
crates/uw_cli/tests/covers_tags.rs: every non-error golden input.uw has at least one `// covers:`
line, and every tag matches the pattern above.

## Done when

- All non-error golden tests tagged; build and tests pass.

## Do not

- Do not edit expected/*.py, Rust sources, or add new golden tests.

## Stop and report if

- A comment line changes a golden output.
- A test still fails after 5 steps on it.
