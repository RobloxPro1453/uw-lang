# T-088: `every day { }` / `every 6 hours { }` (P6, Y6)

Status: ready
Budget: $1.20
Steps: 350

## Goal

Easy-language example §6 (docs/meclis/kolay-dil-taslak.md): a mod writes

```
every day {
    if player.gold < 100 { player.gold += 10 }
}
every 6 hours { say("@Six hours passed.") }
```
and it becomes a Native simple trigger appended to `simple_triggers`.

## Known facts

- simple_triggers record: `(check_interval, ops)` — docs/bilgi/anlam/zaman-ve-olaylar.md:45
  (module_simple_triggers.py:15-17); interval is in game hours (`24` = a day; fractions allowed, :53).
- Top-level items: crates/uw_syntax/src/lib.rs `Item` (On/Override/New/Fn/Save). Emitting appended records:
  see how `on game.start` reaches crates/uw_emit (append to a list via uw_runtime).

## Steps

1. Syntax: `every day { }`, `every <N> hours { }`, `every hour { }` (N a number, may be fractional).
2. Check + emit: one simple trigger per `every`, appended after Native's own list (never inserted, so
   Native indexes keep their order). Body checked like any block (fns, object words, save names work).
3. Golden crates/uw_cli/tests/golden/every_day/ with both forms.

## How to test

The golden fails if the interval or the append position changes.

## Done when

- Build and tests pass; existing goldens unchanged.
