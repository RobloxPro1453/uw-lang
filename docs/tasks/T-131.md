# T-131: easy names for constants, flags and slots, generated from the kit (YÖN-3 L1b)

Status: ready
Budget: $3.00
Steps: 300

## Goal

Kit constants and slots get readable names by rules: `key_left_alt` → `key.left_alt`, `prsntf_read_only` → flag set member, `slot_town_lord` → `town.lord`.

## Known facts

- Rules and numbers: docs/meclis/yon3/dil/D3-SOZLUK.md (read it fully; it was measured with python on the atlas). Decision: docs/meclis/yon3/dil/KARAR-DIL.md §2, §5 (one name per concept; numbered raw access is not "easy").
- Atlas: `target/uw-staging/atlas.json` (in your worktree): `ops` (name, code, signature, lhs, can_fail), `constants` (name, value, module, line). Kit sources (read only): `target/ref/kit/` (= `Module_system 1.171/`), e.g. header_operations.py comments, module_constants.py slots.
- Load the atlas with `uw_atlas::Atlas::from_path`. Put the generator in a new crate `crates/uw_easy` (add to workspace members) with a `uw easy` subcommand ONLY if uw_cli/src/main.rs edits stay to 2-3 lines.

## Steps

1. Prefix dictionary (~40 prefixes, D3 §3) in `kit-meta/easy/prefixes.toml` (key_ → key, ti_ → event, itp_ → item.type …) with evidence lines.
2. Flags vs enums decided automatically (powers of two → flag set). Aliases (same family, same value) kept as aliases, not new names.
3. Slots (module_constants.py `slot_*`): `slot_<kind>_<name>` → `<kind>.<name>`; longest prefix first (slot_party_template_ before slot_party_); real clashes listed.
4. Write `kit-meta/easy/constants.json` and `kit-meta/easy/slots.json` (easy, native, value, family, doc, line).

## How to test

crates/uw_easy/tests/constants.rs (create the crate if T-130 has not; same name `uw_easy`): real atlas: all `key_*` mapped; `slot_town_lord` → `town.lord`; slot_party_template_* not mistaken for party slots; ≥ 550 slots named; fixture test too.

## Done when

- Both json files generated; counts in the report. Build and tests pass.

## Do not

- Do not edit crates/uw_check, uw_syntax, uw_start. Never invent native names.

## Stop and report if

- A test still fails after 5 steps on it.
