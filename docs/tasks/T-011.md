# T-011: UW kılavuzu (user guide) — first version

Status: ready
Budget: $1.00
Steps: 200

## Goal

A Turkish user guide `docs/kilavuz/UW_KILAVUZU.md` that explains, in detail and in plain Turkish for a
modder who does NOT know Module System, everything UW can do TODAY. It will be extended step by step
when new features land, so describe only what exists in the code now (no plans, no invented features).

## Known facts

- Language today (parser `crates/uw_syntax/src/lib.rs`, checker `crates/uw_check/src/lib.rs`, emitter
  `crates/uw_emit/src/lib.rs`): `mod <ad>`, `override menu <menü> { on enter { ... } }` (replaces the
  menu's opening code), `on game.<kanca> { ... }` (appends to a hook script), Native operations as
  `ad(a, b)`; values: Native name / kit constant / `$global` / `:yerel` / number / `"metin"` (ASCII only).
  Comments `//`, `/* */`, `#`. Error codes in uw_syntax (E01xx) and uw_check.
- Commands (`crates/uw_cli/src/main.rs`): `uw build <klasör> [--debug] [--no-install] [--atlas ..]
  [--kit ..] [--python ..] [--modules ..]`, `uw explain <şey> [--all]`, `uw browse [arama]`,
  `uw graph <şey> [--depth N] [--mermaid] [--html <dosya>] [--json <dosya>]`. Read main.rs and each
  module for exact behaviour and flags; run `cargo run -p uw_cli -- --help` style commands if useful.
- Example mod: `examples/praven_start/praven_start.uw`. Owner-facing docs are Turkish (see
  `docs/bilgi/baslangic-akisi.md` for tone).

## Steps

1. Read the code above (and `docs/DEVELOPMENT.md` for build/atlas setup). Every claim must come from
   the code or a command you ran.
2. Write `docs/kilavuz/UW_KILAVUZU.md` in Turkish with sections: Giriş (UW nedir, nasıl çalışır: .uw →
   denetim → kit → oyuna kurulum), Kurulum ve ilk mod (praven_start adım adım), Dil (her yapı için:
   sözdizimi, ne yapar, örnek, sık hata ve hata kodu), Değer türleri, Yorumlar, Komutlar (her komut ve
   her bayrak, örnek çıktı), Hata mesajları tablosu (kod → anlamı), Sınırlar (şu an yapılamayanlar,
   tek cümleyle), "Bu belge nasıl güncellenir" notu (yeni özellik → ilgili bölüme ekle).
3. Use real Native names only (from the example or atlas); never invent a Native name.

## How to test

`cargo build --workspace` still passes (no code change expected). Every command/flag in the guide
appears in main.rs (grep); every error code in the guide appears in the crates (grep).

## Done when

- The file exists, Turkish, all claims backed by code.

## Do not

- Change any code or other docs.

## Stop and report if

- A described behaviour cannot be confirmed from code.
