# T-103: Editable `owner` on towns and castles (owner asked twice: `faction neutral` misleads)

Status: ready
Budget: $1.50
Steps: 400

## Goal

In a `uw new` project, a town/castle record shows who really owns it at game start and the modder can
change it there:

```
party town_1 "Praven" {
    owner swadia            // who gets it at game start (game_start script); change it here
    faction neutral         // engine field; owner above is what the player sees
    ...
}
```

Changing `owner swadia` to `owner vaegirs` and running `uw build-project` makes the game_start script give
that town to the Vaegirs. An unchanged project still builds byte-identical to Native (32/32).

## Known facts

- Native gives centers at game start in `script_game_start` with lines
  `(call_script, "script_give_center_to_faction_aux", "p_town_1", "fac_kingdom_4")`
  (Module_system 1.171/module_scripts.py around lines 486-560; read-only, never write the kit).
- T-081 already finds this owner and prints it as a comment line (`owned by …`):
  crates/uw_decomp/src/project/mod.rs and crates/uw_decomp/tests/owner_t081.rs. Start from that code.
- Game names (`swadia`, `vaegirs`, …) come from the names layer (T-075/T-076, names.uw); a kit id
  (`kingdom_4`, `fac_kingdom_4`) must also be accepted. Never invent a name: resolve through the existing
  name lookup, unknown name = Turkish error with the file line.
- Project loading: crates/uw_decomp/src/project/load.rs; records split by `split_records` (now returns
  `(first_line, text)`), build: crates/uw_cli/src/build_project.rs. Script records hold compiled ops; the
  call is opcode `call_script` with args [script id, party id, faction id] in the atlas form.

## Steps

1. `uw new`: replace the T-081 comment with a real `owner <game name>` line (keep a short comment saying
   what it means). Only centers that have a give_center line get it.
2. Loader: `owner` is not a schema field: take it out before schema parsing, collect `party id → faction`.
3. Build: after loading, find the game_start script's give_center calls; for each center whose `owner`
   differs from the call's faction, rewrite that one argument. Owner on a center with no call line =
   Turkish error (not a silent add). Report each change on stderr in Turkish
   ("Praven: sahibi swadia → vaegirs (game_start)").
4. Tests: tiny atlas (like owner_t081) — read back exact, changed owner rewrites exactly one arg, unknown
   faction errors with file:line; real-atlas test (skip if target/uw-staging/atlas.json missing) that
   Praven shows `owner swadia`.

## How to test

`cargo test --workspace`; then on the real atlas `uw new <tmp>` + `uw build-project <tmp> --compare-native`
must still say 32/32 equal (run it if the kit and atlas exist in your copy; say so if not).

## Done when

- Build and tests pass; the T-081 tests updated, not deleted. Report lists what you could not run.

## Do not

- Touch crates/uw_syntax, crates/uw_check, editors/**, Module_system 1.171/**, lib/**.

## Stop and report if

- The game_start script is not a single record you can find by id, or rewriting an argument would change
  bytes of an unchanged project.
