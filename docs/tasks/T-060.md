# T-060: Readable fields: items (P5)

Status: ready (start only after T-058 is merged)
Budget: $1.00
Steps: 300

## Goal

The fields of these tables print readably with the T-058 types and still read back identical:
items.

## Known facts

- Types and how to declare them: crates/uw_decomp/src/records.rs (T-058: `ref:<table>`, `flags:<prefix>`
  with `enums`/`zero`, `bits` with `parts`, `list:<type>`), example kit-meta/records/troops.toml.
- Bit layouts, flag constants, enum masks: Module_system 1.171/header_items.py (read-only), the field comments
  in the table's module_*.py. Every name used must exist in `atlas.constants` / a table id.
- Measure: `uw roundtrip` (records block: exact count + coverage line `typed N/M, raw-rest K`).

## Steps

1. Type every field whose meaning the kit states (refs to other tables, flag sets, packed numbers, lists of
   refs). Cite the kit line in `source`. A field whose meaning the kit does not state stays `raw`.
2. Add one real-atlas test per table in crates/uw_decomp/tests/readable_t060.rs (skip if atlas missing):
   all records exact, and the typed fields appear readable in the printed text (assert 2-3 known examples).
3. Lower `raw-rest` where the kit explains the leftover bits; report what remains and why.

## How to test

The per-table test fails if any record changes or a typed field still prints a bare number.

## Done when

- All listed tables exact; report the coverage line for each table (before/after).

## Do not

- Touch any file except kit-meta/records/<these tables>.toml and crates/uw_decomp/tests/readable_t060.rs.
  Core bugs: finish blocked and describe them (other lanes share records.rs).

## Stop and report if

- A layout in the kit contradicts the atlas values. A test still fails after 5 steps.
