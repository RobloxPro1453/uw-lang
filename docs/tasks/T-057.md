# T-057: `uw build-project <dir>`: build a project folder with the kit (P3b)

Status: ready
Budget: $1.50
Steps: 350

## Goal

`uw build-project <dir> [--compare-native] [--no-install]` loads the project folder, writes the whole-table
modules, runs the kit and (with `--compare-native`) reports how many output `.txt` files are byte-identical
to Native. Without `--no-install` it installs like `uw build` does.

## Known facts

- crates/uw_cli/src/build_project.rs exists: `modules(atlas, records)` and `build_and_compare(...)`; today
  only `--native-check` (modules from the atlas itself; measured 32/32 byte-identical). Extend this file.
- Loader: `uw_decomp::project::load::load` (another lane, T-056, fills it; until then it returns an error —
  your tests must not depend on its result; test your own parts with a fake records map).
- Block-aware parse closure: see `check_project` in crates/uw_cli/src/new.rs.
- Install: crates/uw_cli/src/build.rs step 5 (marker `.uw-mod`, never overwrite a folder without it). Reuse
  that code (make a small `pub(crate)` function if needed); do not change its safety rules.
- `build_and_compare` always compares; split it so the comparison is optional and its numbers are returned.

## Steps

1. Parse the arguments; load the atlas and schemas as `uw new --check` does; call `load`; on errors print
   each line and stop before the kit runs.
2. Build; print the kit problems; `--compare-native` prints `outputs N/32 byte-identical` and the differing
   files; exit non-zero on any failed step.
3. Install unless `--no-install` (mod name = project folder name), with the existing safety rules.
4. Tests: argument parsing; with a fake records map: the module texts start with `from native_` and name
   each table's variable; `--native-check` still works.

## How to test

Unit tests on the pieces above; the full kit run is checked by Claude after merge (needs Python 2.7).

## Done when

- Tests green; `uw build-project --native-check` still prints 32/32.

## Do not

- Touch crates/uw_decomp (another lane) or the kit; never weaken the install safety checks.

## Stop and report if

- A test still fails after 5 steps.
