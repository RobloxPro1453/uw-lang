# T-008: uw browse — "leads to" list next to "used by"

Status: ready
Budget: $0.90
Steps: 220

## Goal

In `uw browse` the owner switches the lower right list between "used by" (who mentions this) and "leads
to" (what this mentions) with one key, and follows either with Enter.

## Known facts

- `crates/uw_cli/src/tui.rs`: `App`, key handling, drawing and tests (ratatui TestBackend). Read it all
  first. Rows are `UseRow::Header` / `UseRow::Site`; `App::show` fills them from `Detail.uses`.
- Model API (`crates/uw_cli/src/model.rs`): `model.outgoing(&Target) -> &[(Target, Option<String>)]`,
  `UseSite`, `entry_label`, `entry_hint`.
- Fixture: `crates/uw_cli/tests/fixtures/atlas_refs.json`.

## Steps

1. Add a list mode to App: `UsedBy` (today's behaviour) and `LeadsTo`. Key `g` toggles it when the lower
   list is focused, and in results focus only when the query is empty (else `g` types into the search).
2. LeadsTo rows from `model.outgoing(current)`: only `Target::Entry`, grouped by table with a
   `table (n)` header like UsedBy, one `UseSite` per target (label, hint, place = where the target is
   defined, ops with counts).
3. Title ` leads to N places ` in LeadsTo mode; help bar shows `g` with the other mode's name.
4. Enter / Esc history work in both modes; the mode stays when jumping.

## How to test

New tests in the existing `tests` module: on script `game_start` toggling shows its targets; Enter opens
one; Esc comes back with the mode kept; typing `g` into a non-empty search adds the letter. Existing
tests pass unchanged.

## Done when

- Tests pass; no build warnings.

## Do not

- Touch model.rs, explain.rs, build.rs, main.rs.
