# T-110: VS Code shows what a name means when you hover it

Status: ready
Budget: $0.80
Steps: 250

## Goal

Hovering `praven`, `king_harlaus`, `player.gold` or a `fn` word in a .uw file shows a short Turkish
explanation (what it is, its Native id, where it is defined) — the same knowledge as `uw explain`.

## Known facts

- `uw explain <name>` exists (crates/uw_cli/src/explain.rs, model.rs; tests crates/uw_cli/tests/explain.rs).
- `uw words --json` (T-104) lists names with a one-line `detail`; extension.js caches it per folder and has
  a pure `parseWords`. Reuse that cache for a cheap first answer; call `uw explain --json <name>` only on
  hover for the long text.
- No npm packages; plain `vscode` API; tests runnable with plain `node` (see editors/vscode/test/).

## Steps

1. `uw explain --json <name> [folder]`: one JSON object `{"name","kind","native_id","text"}` (text = the
   current human output). Keep the plain output unchanged.
2. extension.js: a HoverProvider for `uw` (word under cursor incl. dots), cached per name, shows markdown.
3. Tests: explain --json in crates/uw_cli/tests/explain.rs; pure `hoverMarkdown(obj)` tested in
   editors/vscode/test/hover.test.js.

## How to test

`cargo test --workspace`; `node editors/vscode/test/hover.test.js`.
