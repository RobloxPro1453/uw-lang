# T-054: Decompiler prints `for`, `require`, `attempt` (P2)

Status: ready (start only after T-052 and T-053 are merged)
Budget: $2.00
Steps: 450

## Goal

`uw roundtrip` shows almost no Native-shaped lines: loops print as `for :i in range(a, b) { }`, condition
operations standing in a block print as `require <cond>`, and `try` blocks that are not a clean `if` print as
`attempt { } else attempt { } else { }`. Still 9113/9113 exact and 12815/12815 records.

## Known facts

- Decompiler: crates/uw_decomp/src/decompile.rs (structured mode already prints `if`, compares, `and/or/not`
  when they round-trip). `uw roundtrip` keeps a block structured only if it compiles back identical; the
  breakdown (T-050) prints the remaining Native-shaped lines by pattern.
- Today [ÖLÇÜ]: 5518 Native-shaped lines: guard `neg|` 1865, `this_or_next|` chain outside an if head 549,
  compute-then-test arm 527, `else_try` in a loop body 77, other 2500 (mostly loop `try_end`).
- Syntax and meaning: doc comments of `uw_syntax::Stmt::{Require, Attempt, For}`; lowering is T-053.
- Loop kinds: any op named `try_for_<kind>` in the atlas op table; the loop variable is its first argument.

## Steps

1. Loops: `try_for_<kind>(var, args…)` … matching `try_end` → `for var in kind(args…) { … }` when the body has
   no top-level `else_try` (that case stays raw).
2. Guards: a condition operation (with its `this_or_next|` chain and `neg|` flags) standing in a block
   (not an `if` head) → `require <cond>`, reusing the existing condition printer.
3. `try_begin … else_try … try_end` that is not a clean `if` chain → `attempt` arms, conditions inside as
   `require`; the last arm prints as `else { }` when it has no `require`.
4. Keep the existing choice rule: structured text only when it compiles back identical, else raw.
5. Tests: one small block per pattern (text + compiles back identical); the T-050 breakdown on the real atlas.

## How to test

Per-pattern tests assert the printed text and the round trip; the real `uw roundtrip` numbers are the proof
(report before/after of the breakdown).
