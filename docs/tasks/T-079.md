# T-079: UW's first word library `lib/core.uw`, loaded by every `uw build` (P6)

Status: ready
Budget: $1.50
Steps: 400

## Goal

Every mod can use UW's own words without defining them: `give_gold(1000)`, `move_near(praven)`,
`show_map()`, `say("@Hello")`. The words are plain UW `fn`s (T-078) in `lib/core.uw` at the repository
root, readable by anyone; `examples/menu_demo` is rewritten with them and with game names (T-077).

## Known facts

- `fn` syntax and inlining: T-078 (docs/tasks/T-078.md, its report). Game names in `uw build`: T-077.
- Which Native operation each word uses, with traps: docs/bilgi/anlam/oyuncu-varliklari.md (gold §1,
  items §2, troops §3, stats §4), hareket-ve-harita.md §2, menuler.md §10. Use only operations listed there.
- `kit-meta/` is found by searching upward from the working folder (crates/uw_cli/src/roundtrip.rs
  `find_schemas`); find `lib/` the same way.

## Steps

1. Write lib/core.uw (each fn with a one-line comment citing its anlam page line): give_gold, take_gold
   (takes at most what the player has: store_troop_gold + compare, as the anlam page shows), give_item,
   take_item, add_troops(:troop, :count), remove_troops(:troop, :count), add_renown, add_honor,
   move_near(:party), show_map(), say(:text).
2. `uw build`: parse every lib/*.uw file as extra sources before the mod's files; a lib file may hold only
   `fn` items (else an error naming the file). A mod fn with the same name as a lib fn is an error.
3. Rewrite examples/menu_demo/*.uw with the words and game names; same in-game behaviour.

## How to test

Golden crates/uw_cli/tests/golden/lib_words/: input using give_gold, take_gold, move_near, show_map; expected
.py shows the inlined Native operations. A test that the real lib/core.uw parses and checks with no error
against the fixture atlas (or the real atlas when present).

## Done when

- `uw build examples/menu_demo --no-install` succeeds (put the output in the report). Build and tests pass.

## Do not

- Change crates/uw_syntax, crates/uw_check, crates/uw_lower, crates/uw_decomp (report needed changes).

## Stop and report if

- A word needs a return value or use inside a condition (not supported yet). A test still fails after 5 steps.
