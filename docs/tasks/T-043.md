# T-043: Operation blocks inside record text: `ops { … }` (P3a)

Status: ready
Budget: $2.00
Steps: 400

## Goal

In record text, every field (or nested value) that is a Native operation block prints as readable UW code
`ops { … }` (the decompiler's text) instead of raw numbers, and parses back to the identical atlas value.
`uw roundtrip` measures records this way: 27 tables still 12815/12815 exact.

## Known facts

- Record core: crates/uw_decomp/src/records.rs (`print`, `parse`, `roundtrip_table`, `Value`, `to_json`).
- Block finder: `uw_decomp::extract` gives `Block {table, index, path, label, ops}` for every op block;
  `path` = list/tuple positions from the record value root, `{"list": …}` wrappers not counted
  (crates/uw_decomp/src/lib.rs, extract/*.rs). `parse_ops` reads a block's JSON.
- Decompile + compile of one block already exist and are 9113/9113 exact: see how `uw roundtrip` builds its
  `print` and `compile` closures in crates/uw_cli/src/roundtrip.rs (`uw_decomp::roundtrip::run`).
- The records measure in `uw roundtrip` is in crates/uw_cli/src/roundtrip.rs (added by T-034).

## Steps

1. In records.rs add `ops_to_json(&[RawOp]) -> Json` (inverse of `parse_ops`; test both ways on real
   blocks), `print_with_blocks(schema, entry, paths: &[Vec<usize>], print_block: &mut dyn FnMut(&Json) -> String)`
   and `parse_with_blocks(schema, text, compile: &mut dyn FnMut(&str) -> Result<Json, String>)`.
   Printed form: `ops {`, newline, the block text indented 4 more spaces, `}`. Parsing finds the matching
   `}` (aware of strings and nested braces) and hands the inner text to `compile`. `print`/`parse` keep
   working unchanged for callers that pass no blocks.
2. Wire the records measure of `uw roundtrip` to the block-aware pair (closures built like the ops ones).
3. Tests: a tiny-atlas unit test with a fake block printer/compiler; a uw_cli test on the real atlas
   (skip when missing) asserting menus 217/217 and scripts 610/610 exact with blocks shown as `ops {`.

## How to test

The real-atlas test fails if a block field is printed raw (assert the menus text contains `ops {`) or if
any record value changes.

## Done when

- `uw roundtrip`: records 12815/12815 exact, ops 9113/9113; report the numbers. Workspace tests green.
