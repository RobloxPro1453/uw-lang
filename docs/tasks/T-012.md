# T-012: Official Turkish text in uw explain and uw browse

Status: ready
Budget: $0.80
Steps: 200

## Goal

When the game's official Turkish translation is installed, `uw explain` and `uw browse` show the
Turkish in-game text next to the English one (menus, menu options, dialog lines, troops, items,
parties...), so the owner can find things by what he sees in a Turkish game.

## Known facts

- `crates/uw_cli/src/tr.rs`: `load_dir(dir) -> HashMap<key, text>` and `default_dir()` exist but are
  unused (`#[allow(dead_code)]`). Keys are the engine ids: `menu_start_game_0|...`,
  `mno_start_male|Erkek`, `dlga_start:...|...` (docs/bilgi/diyaloglar-ve-ceviri.md:10).
- `crates/uw_cli/src/model.rs`: `Model::new(atlas)`, rows with `hint` (English in-game name, see
  `entry_hint`), `search` matches `hint_lc`. `main.rs::load` builds the model.
- CLI tests: `crates/uw_cli/tests/explain.rs` run the binary on `tests/fixtures/atlas_refs.json`.

## Steps

1. Give the model an optional Turkish map (`Model::with_tr` or a field set after `new`); `main.rs`
   loads `tr::default_dir()` (and a new `--tr <dir>` flag on explain/browse/graph) when present, silent
   when missing.
2. Map each entry to its key (figure out per table from the csv files and atlas ids; menus `menu_<id>`,
   options `mno_<id>`, dialogs the `dlga_` id the atlas already builds); only exact keys, no guessing.
3. explain: show `tr: "<metin>"` under the English hint; browse: show it in the detail pane; search
   also matches the Turkish text (lowercase, Turkish i/İ handled by `to_lowercase`).

## How to test

Add a small fixture dir `crates/uw_cli/tests/fixtures/tr/` (csv with keys that exist in
atlas_refs.json) and a CLI test `uw explain <x> --tr <fixture dir>` that prints the Turkish line, and
one that finds the entry by a Turkish word. Without `--tr` and no default dir the output is unchanged.

## Done when

- Tests pass; no warnings; `#[allow(dead_code)]` removed from tr.rs.

## Do not

- Touch build.rs, flow_json.rs, graph_export.rs, uw_* crates other than uw_cli.

## Stop and report if

- The key for a table cannot be derived from csv + atlas data.
