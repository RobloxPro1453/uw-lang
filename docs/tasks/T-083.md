# T-083: `player.*` objects in lib/core.uw (P6)

Status: ready
Budget: $1.20
Steps: 300

## Goal

Every mod can write the easy-language example as it stands in docs/meclis/kolay-dil-taslak.md §1:
`player.gold += 1000`, `player.gold -= 50`, `if player.gold >= 100 { }`, `player.renown += 10`,
`player.honor += 1`, `say("@...")`, `move_near(praven)`.

## Known facts

- Object form maps to dotted fns (T-082): `x.y += e` -> `x.y.add(e)`, `-=` -> `x.y.remove(e)`, `=` ->
  `x.y.set(e)`, a dotted operand -> `x.y.get(:tmp)`. Golden example: crates/uw_cli/tests/golden/object_words/.
- lib/core.uw (T-079) is loaded by every `uw build`; words cite docs/bilgi/anlam/*.md lines.
- Operations and traps per object: docs/bilgi/anlam/oyuncu-varliklari.md (gold §1, stats §4).

## Steps

   `player.renown.get/add`, `player.honor.get/add`, `player.level.get` — only where the anlam page names
   the operation; skip (and list in the report) any whose operation is not there.

   (no `save` yet: keep `$g_uw_rich`).
