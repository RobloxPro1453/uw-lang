# T-056: `uw.lock` and reading a project folder back into whole tables (P3b)

Status: ready
Budget: $1.50
Steps: 400

## Goal

`uw new` also writes `uw.lock` (the record order of every table), and `project::load` reads a project
folder back into every table's values in that order, so the kit numbers records exactly as Native does.
Decision: docs/arsiv/meclis-yon1-yon2/YON2-KARAR.md §3.3-3.4.

## Known facts

- Stub to fill: crates/uw_decomp/src/project/load.rs (`load`, read its doc comment). Export and verify:
  crates/uw_decomp/src/project/mod.rs (`export`, `verify_with`, `split_records`), layout.rs.
- `uw new` CLI: crates/uw_cli/src/new.rs. Records: `records::parse_with_blocks`, `record_id`.
- Order matters: Native code computes with record numbers (`docs/bilgi/sira-baglari.md`: 586 sites),
  so a record's position must never move.

## Steps

1. `uw.lock` (TOML, written by `export` into the project root): `kit_hash`, and per table the ids in atlas
   order (`[tables] factions = ["no_faction", …]`). Ids exactly as `record_id` prints them.
2. `load`: read every `.uw` file under the project (any folder: the user may move files), split records,
   parse, then per table: lock order first; a lock id with no record → error
   `"<table> <id>: kayıt silinmiş; silme henüz yok (P3b v1), kaydı geri koy"`; a record id not in the lock →
   appended after the lock ids in file-path then text order; the same id twice → error naming both files;
   a broken `uw.lock` (unreadable, other kit_hash) → error, never a silent reorder.
3. Tests (tiny atlas + temp folder): export → load gives the atlas values in atlas order; a moved file still
   loads; a deleted record → the error; a duplicated record → the error; a new record → last; a lock with a
   wrong kit_hash → the error. Real atlas (skip if missing): export → load → values equal the atlas values by
   `records::record_difference` for all 12815.

## How to test

Each test checks the exact order or the exact error text; the real-atlas test fails if any record moves or
changes.

## Done when

- Tests green; report the real-atlas numbers.

## Do not

- Touch crates/uw_cli/src/build_project.rs (another lane) or records.rs.

## Stop and report if

- A test still fails after 5 steps.
