# T-109: `area` + `on enter` — something happens when the player enters a map region (easy-language §5)

Status: ready
Budget: $2.00
Steps: 500

## Goal

```
area mountain_road [(10, 20), (40, 20), (40, 60), (10, 60)]

on enter mountain_road when time.hour >= 12 {
    if player.has(iron_shield) {
        player.remove(iron_shield)
        say "Bandits took your shield!"
    }
}
```
compiles; in game the block runs once each time the player's party goes from outside to inside the polygon
(not every hour while inside).

## Known facts

- Read first: docs/meclis/kolay-dil-taslak.md §5 and docs/bilgi/anlam/bolgeler-ve-dogma.md (map
  positions, units), docs/bilgi/anlam/zaman-ve-olaylar.md (simple_triggers, time). `every day { }` (T-088,
  golden every_day) already makes a simple_trigger: copy its path through uw_syntax → uw_check → uw_emit.
- Coordinates are world-map units as in module_parties.py positions (e.g. Praven (-174, 26) — check it in the
  kit). In game read the party position with `party_get_position` + `position_get_x/y`; these return
  fixed-point values: call `set_fixed_point_multiplier, 100` first and compare against coordinates × 100.
  Verify each operation name in the atlas/kit before using it; never invent one.
- Edge detection needs one saved global per area (`$uw_area_<name>_inside`, 0/1).

## Steps

1. Syntax: top-level `area <name> [(x, y), …]` (≥ 3 points, numbers may be negative/decimal) and
   `on enter <area> [when <cond>] { block }`. Errors in Turkish with position: unknown area, < 3 points.
2. Lower: a simple_trigger with a short interval (0.25 h; say so in a comment) that computes inside/outside
   with a ray-casting point-in-polygon (as ops, or a generated script `uw_area_<name>_contains`), fires the
   block only on outside→inside, and stores the flag.
3. Golden crates/uw_cli/tests/golden/area_enter/ and a Turkish CHECKUP item (step by step: walk into the
   region near a named town, see the message once, leave and re-enter).
