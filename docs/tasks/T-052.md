## Goal

UW text with the three new statements parses into the AST nodes that already exist:
`Stmt::Require`, `Stmt::Attempt`, `Stmt::For` (crates/uw_syntax/src/lib.rs, read their doc comments).
Decision: docs/meclis/YON2-KARAR.md §4 (+ `for`: P2 addendum in the same file).

## Known facts

- Parser: crates/uw_syntax/src/lib.rs; statements start in `fn stmt` (`if` → `if_stmt`); `for` is
  rejected today by `keyword_error` (remove `for` from that list). Conditions: the same parser `if` uses.
- Syntax:
  - `require <cond>` — one statement, ends at newline or `;`.
  - `attempt { … }` followed by any number of `else attempt { … }`, optionally one final `else { … }`
    (that is one more arm). `else if` after `attempt` is an error with a hint.
  - `for <$global|:local> in <word>(<args>) { … }`; `<word>` → `kind`, args like a call's arguments
    (may be empty: `for :p in parties() { }`).
- Error rules (KARARNAMELER "Sözdizimi: süslü parantez"): never only "unexpected end of file"; point at the
  unclosed `{`; one-line hints for Python habits (`for i in range(10):` → the UW form).
