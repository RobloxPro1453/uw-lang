# T-044: `uw new <dir> --from native` writes the project folder (P3a)

Status: ready
Budget: $1.50
Steps: 350

## Goal

The owner runs `uw new hikayem --from native` and gets a folder with every Native record as UW text,
grouped by `layout::path_for`, a `uw.toml` and a short Turkish `README.md`; `uw new --check hikayem` reads
the folder back and says every record is exact. Decision: docs/arsiv/meclis-yon1-yon2/YON2-KARAR.md §3.2.

## Known facts

- Skeleton to fill: crates/uw_decomp/src/project/mod.rs (`export`, `ExportSummary`). `layout.rs` belongs to
  another lane (T-045): call `layout::path_for`, never edit it.
- Records: crates/uw_decomp/src/records.rs (`Schema::from_path`, `print`, `parse`); schemas in
  kit-meta/records/*.toml (27). Atlas loading: see crates/uw_cli/src/roundtrip.rs.
- Turkish descriptions exist for some names: kit-meta/aciklama/{menus,scripts,mission_templates,
  presentations,scenes}.json (look at the shape; use the short text if present).

## Steps

1. Fill `export`: create folders, write files (UTF-8, `\n`), refuse a non-empty `out` folder (data-loss
   rule: never overwrite). Each file starts with a `//` line naming the table and the record count; per
   record a `// <display name> — <short description>` line when known (display name = the record's name
   field if it is a string; description from kit-meta/aciklama).
2. Add `pub fn verify(...)` in mod.rs: split each file into records (comment lines skipped), parse with a
   given parse function, compare with the atlas by id; return records / exact / failed / first failures.
3. `uw.toml` with `base = "native-export"` and the atlas `kit_hash`; `README.md` (Turkish, at most 30
   lines): what the folder is, that it is not compiled yet (P3b), how to check it.
4. CLI in crates/uw_cli: `uw new <dir> --from native [--atlas <path>]` and `uw new --check <dir>`; add both
   to the help text. Use `records::print` / `records::parse` as render/parse (T-043 will swap them).
5. Tests: tiny atlas → export to a temp folder → verify all exact; a non-empty folder is refused; real atlas
   (skip if missing): export + verify 12815/12815.

## How to test

The export→verify test fails if a record is missing, duplicated or no longer parses to the atlas value; the
refusal test fails if an existing folder could be overwritten.

## Done when

- Real atlas: file count and 12815/12815 exact in the report. Workspace tests green.

## Do not

- Edit project/layout.rs, records.rs, decompile.rs, uw_decomp/src/roundtrip.rs, kit-meta/.

## Stop and report if

- A test still fails after 5 steps.
