# T-134: continuous blocks, rates, keys and agent fields at runtime (mission dispatcher)

Status: ready

## Goal

Top-level `while in mission {}`, `while cond {} otherwise {}` and `x += r per second` work every frame in every mission with the player, through ONE generated dispatcher; `var agent.X` is initialised when an agent spawns.

## Steps

1. src/lower/continuous.rs: collect every continuous block of every file in order (main first, then features by path); generate script `uw_mission_frame` that measures elapsed ms since its previous run (store in a global, reset on mission start) and runs each block inside its own try_begin/try_end.
2. `while cond {A} otherwise {B}` → try_begin cond A else_try B try_end inside the frame script.
3. Rates: inside continuous blocks `r per second` becomes `r * elapsed_ms / 1000` in fixed-point (r is thousandths) — no truncation drift: keep the fractional remainder per statement in a global.
4. Emit `Lowered.mission_triggers`: one `Interval(0)` trigger (target WithPlayer) calling `script_uw_mission_frame`; one `Event("ti_on_agent_spawn")` trigger initialising every `var agent.X` slot of the spawned agent (store_trigger_param_1).
5. Outside a continuous block a rate is an error.

## How to test
