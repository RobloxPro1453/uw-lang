# T-022: Checker: check one Native block (raw mode)

Status: ready
Budget: $1.50
Steps: 300

## Goal

`uw_check::check_block` checks and lowers one statement block the way Native wrote it, so a decompiled
block can be compared with the original (kaldıraç plan, docs/meclis/DEVIR.md 00000).

## Known facts

- crates/uw_check/src/lib.rs: `check` (line ~834) builds a checker; `ops(&[Stmt]) -> Vec<Op>` turns a
  statement list into operations; `call` looks the op up with `atlas.op(name)`; `value` resolves names;
  `check_text` rejects non-ASCII (E0204); `min_args` gives E0203.
- `Op.name` may carry flags (`neg|eq`); crates/uw_decomp `to_raw` splits on `|` and ORs the codes.
- T-021 (parallel) makes the parser produce `Call.op.text == "neg|eq"`; build such calls by hand in
  your tests (see the `op_call` helper in the tests module).

## Steps

1. `pub fn check_block(atlas: &Atlas, file: &SourceFile, stmts: &[Stmt]) -> Result<Vec<Op>, Vec<Diagnostic>>`
   (adapt the exact types to what the checker already uses; document them).
2. Native mode inside check_block only: flagged names (`neg`, `this_or_next` prefixes, each part must
   exist; Op.name keeps the full flagged text); every Native op accepted as a plain call, including
   try_begin / else_try / try_end / try_for_*; no E0204 and no E0203 (Native is the reference);
   strings and names resolved as today. `check` (user files) keeps its current behaviour exactly.
3. Temporaries (`:_uw0`) must not appear for plain comparisons / single-op `or` (they do not today).

## How to test

Tests in uw_check: `check_block_keeps_flags` (call `neg|this_or_next|eq` -> one Op with that name),
`check_block_accepts_control_ops` (try_begin, try_for_range(:i, 0, 3), try_end -> 3 ops),
`check_block_native_text_ok` (non-ASCII text accepted here but still E0204 through `check`),
`check_block_if_matches_lowering` (an `if $x > 1 { … } else { … }` gives try_begin, gt, …, else_try,
…, try_end).
