# T-006: impact report — what stops being reachable after an override

Status: ready
Budget: $0.90
Steps: 220

## Goal

When a mod replaces a Native entry's code, say in plain words which Native things are no longer reached
from anywhere ("these will never open now").

## Known facts

- `crates/uw_cli` is a binary crate. Add ONLY one `mod impact;` line to `src/main.rs`; no command
  wiring. `#[allow(dead_code)]` on pub items not yet used; no build warnings.
- Model API (`crates/uw_cli/src/model.rs`, read it): `Target` (derives Ord), `model.outgoing(&Target)`,
  `model.engine_roots()` (hook scripts, menu #0, menu start_phase_2, all triggers and simple triggers),
  `model.label`, `model::entry_hint`, `model::kind_of`, `model::short`.
- Fixture shape: `crates/uw_cli/tests/fixtures/atlas_refs.json` (read it; copy its structure).

## Steps

1. New file `crates/uw_cli/src/impact.rs`: `pub fn unreachable_after(model: &Model, cut: &[Target]) ->
   Vec<Target>`: the set reachable from `engine_roots()` over outgoing edges between `Target::Entry`
   nodes, computed twice: normally, and ignoring the outgoing edges of every entry in `cut` (a cut entry
   itself stays reachable if something reaches it). Return reachable-before minus reachable-after,
   sorted.
2. `pub fn render(model: &Model, lost: &[Target]) -> String`: "" when lost is empty; else first line
   `impact: N Native entries are no longer reached from anywhere:` then one line per table, sorted by
   table name: `  menus (2): menu_a "hint", menu_b` (hint via short(hint, 30), omitted when None).

## How to test

New fixture `crates/uw_cli/tests/fixtures/atlas_impact.json`: menus table with menu #0 `start` (root)
and menus `a`, `b`, `c`; hook script `game_start` (hooks list contains it) with a statement
`[2060, "mnu_a"]`; menu a's operations mention "mnu_b", menu b's mention "mnu_c"; script `other` (not a
hook, nobody mentions it) mentions "mnu_c". Ops list must include code 2060 named jump_to_menu.
Tests: cut [menu a] loses b and c; cut [menu b] loses only c; cut [] loses nothing; render for the
first case equals an exact string.

## Done when

- Tests pass; no build warnings.

## Do not

- Touch model.rs, tui.rs, explain.rs, build.rs.

## Stop and report if

- engine_roots or outgoing do not behave as described.
- A test still fails after 5 steps on it.
