# T-081: Show who owns a town at game start (P5)

Status: ready
Budget: $1.00
Steps: 250

## Goal

Praven's record says `faction neutral` because the kit writes fac_neutral (module_parties.py:82); the real
owner is given at game start by a script (module_scripts.py:491:
`(call_script, "script_give_center_to_faction_aux", "p_town_6", "fac_kingdom_1")`). The exported record
gets a comment line under its name: `// at game start: owned by swadia (game_start script)`.

## Known facts

- The record comment is built in `comment()` crates/uw_decomp/src/project/mod.rs:224 (export, `uw new`).
- Operation blocks of scripts: `uw_decomp::extract::all(atlas)` (used by crates/uw_cli/src/new.rs). A call is
  op `call_script` with args `script_give_center_to_faction_aux`, `p_…`, `fac_…` (RawArg::Str).
- With game names installed, `atlas.game_name("fac_kingdom_1")` gives `swadia`; else print the kit id.

## Steps

1. In project export: scan the `game_start` script (and scripts it calls directly, one level) for
   `call_script script_give_center_to_faction_aux|script_give_center_to_faction <party> <faction>`;
   build party -> faction.
2. Add the comment line for those party records (after the existing name comment). Comments are ignored
   when reading back, so load/verify must stay exact.
