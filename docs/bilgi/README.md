# Bilgi tabanı (süzülmüş, kanıtlı)

Module System ve Warband motoru hakkında **denenerek ya da kitten okunarak öğrenilmiş** bilgiler. Ham madde (Manus/Perplexity raporları, forumlar, örnek modlar) buraya doğrudan girmez; süzülür, doğrulanır, kemiği yazılır.

Neden konu başına dosya: ajan yalnız ilgili konuyu okur (token ve dikkat tasarrufu, ARCHITECTURE'daki modülerlik ilkesinin belge karşılığı). Bağlantılar düz Markdown (`[menüler](menuler.md)`): GitHub'da da, Obsidian'da da çalışır.

## Kanıt etiketleri (her iddia birini taşır)

- **[KİT]** kitte doğrulandı — `dosya:satır` ile.
- **[DENEY]** deneyle doğrulandı — deney adı (D1…) ve tarih.
- **[MOD]** gerçek bir modun kaynağında görüldü — `ornek-modlar/<mod>/dosya:satır`; motor gerçeği sayılmaz, kalıp örneğidir.
- **[İDDİA]** rapor/forum iddiası, doğrulanmadı — kaynağı yazılır; karar buna dayanamaz.
