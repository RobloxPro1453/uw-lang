# 16-warband-ai-chat - infrastructure scan

**Mod:** an AI-chat layer for Warband. A presentation collects free text, packs the NPC context into a JSON file, an external process answers in another JSON file, and a companion can execute a queued multi-step travel/fetch mission. The snapshot has 12 `module_*.py` files but **no `module_scripts.py` / `module_constants.py`**; the mod's own additions visible here are about 450 gameplay lines in 4 files (1 presentation, 1 mission-trigger helper inserted 5x, 1 world-map trigger, 2 simple-trigger blocks) plus 22 lines of engine-extension opcodes in `header_operations.py`. Script count and the setup of `$g_open_ai_chat_flag`/`$g_ai_talk_troop` cannot be verified because those files are missing.

## Top 5 things a language should give built in

1. A first-class bidirectional channel to an external process (streams/sockets or events), so no fixed JSON file names, manual file polling or clear-after-read dance is needed.
2. Structured records and lists with named fields and literal syntax, replacing dicts built through string registers and repeated `dict_set_*` calls.
3. A real UI toolkit: text input with focus, modal panels, status/progress labels and named key actions, instead of raw scancodes and hand-placed overlays.
4. Timers/schedulers with cancel and timeout primitives that work in every context (presentation, world map, mission), instead of frame counters and hard-coded trigger periods.
5. Persistent, typed per-object data and collections (fields on troops/parties, lists, queues) instead of fixed numeric slots and manual shift loops.
