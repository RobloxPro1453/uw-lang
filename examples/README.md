# Examples

Example mods written in UW. Build one with `uw build examples/<name>` (add `--no-install` to compile without installing into Warband).

- `alex/`: a custom start in a town, a stamina resource with a HUD bar and an Alt-to-sprint mechanic. Stamina and sprint are ordinary UW code in `features/`.
- `steve/`: the same stamina and sprint features without the custom start flow.
- `praven_start/`: record-oriented example: character creation as in Native, no prologue, start next to a chosen town.
- `menu_demo/`: record-oriented example: changes a menu's text, renames and removes options, and adds a conditional option.
